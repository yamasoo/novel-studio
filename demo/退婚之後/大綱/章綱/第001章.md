# 第1章 退婚當天

## 本章四問
1. 主角這章想做什麼：不讓林家在退婚時丟盡顏面
2. 誰或什麼阻止他：沈既白當眾退婚、大伯母落井下石
3. 這章結束後局面變成什麼：林晚收下退婚書，但讓沈既白失態；玉珮第一次發熱
4. 讀者為什麼還要往下看：玉珮為什麼發熱？

## 本章功能與目標情緒
- 功能：推進
- 讀者看完的主要感受：憋屈轉痛快

## 情節點
1. 沈家送來退婚書，林晚在後院餵雞
2. 正廳上沈既白提退婚，林晚反問婚書上的印是誰蓋的
3. 大伯母笑著說聘禮不必退，算林家賠禮
4. 林晚拿出半塊玉珮放在婚書上，沈既白伸手要看，被她收回
5. 玉珮在掌心發熱

## 章末鉤子
- 停在：未解問題：玉珮發熱
