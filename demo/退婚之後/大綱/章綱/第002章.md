# 第2章 浮字

## 本章四問
1. 主角這章想做什麼：弄清楚玉珮為什麼發熱
2. 誰或什麼阻止他：頭痛、小翠擔心、大伯母派人盯著
3. 這章結束後局面變成什麼：玉珮浮出「沈家欠的，不止一紙婚書」
4. 讀者為什麼還要往下看：這行字是什麼意思？

## 本章功能與目標情緒
- 功能：揭露
- 讀者看完的主要感受：好奇

## 情節點
1. 夜裡林晚檢查玉珮，斷口浮出一行字
2. 字一炷香後消失，林晚頭痛
3. 小翠說大伯母派了婆子守院門
4. 林晚決定明天去鋪子查三年前的帳
