# 第3章 鋪子裡的帳

## 本章四問
1. 主角這章想做什麼：在鋪子查到三年前的帳
2. 誰或什麼阻止他：掌櫃推說帳本被大伯母收走
3. 這章結束後局面變成什麼：林晚靠記性默出關鍵的一頁，發現一筆對不上的鹽引
4. 讀者為什麼還要往下看：那筆鹽引去了哪裡？

## 本章功能與目標情緒
- 功能：爽點
- 讀者看完的主要感受：痛快

## 情節點
1. 林晚到鋪子，掌櫃支支吾吾
2. 掌櫃說帳本三天前被大伯母的人拿走
3. 林晚當場默寫出三年前三月的帳
4. 帳上有一筆鹽引在同一天被轉了兩次
5. 掌櫃臉色發白，說出「周先生」三個字

- 停在：反轉：沈家帳房介入過林家的帳
