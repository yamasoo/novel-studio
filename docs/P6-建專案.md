# P6 Step 5：建專案（`studio/spawn.py`、`tools/spawn.py`）

> 用風格指紋與結構 DNA 建出一本**可以馬上開始填**的新書骨架。不呼叫模型。

## 產出什麼

| 項目 | 內容 |
|---|---|
| 資料夾 | `正文／候選／大綱（章綱、卷綱）／追蹤（章節摘要、角色狀態）／設定（角色、勢力、世界觀、章節結構）／範例／_範本` |
| `_範本/` | 18 份（從示範書複製；那份被 `check_parity` 盯著，不會缺） |
| `CLAUDE.md` | 書名、語言、視角、章長、對白比例＋「骨架從哪本書來」 |
| `設定/文風.md` | 基本設定＋句子節奏＋對白＋**文字指標表**（`shared.parse_metrics` 讀得到） |
| `設定/章節結構/結構.md` | 視角依據、章長分佈、章長曲線、對白節奏、段落節奏 |
| `設定/風格指紋.json`、`設定/結構DNA.json` | 副本，之後要重抽或比對都用得到 |
| `追蹤/*.md`、`大綱/全書大綱.md`、`大綱/卷綱/卷綱_第一卷.md` | 從範本複製、狀態標成「草稿」 |
| `大綱/章綱/第001–00N章_待填.md` | 空白章綱模板（本章四問／情節點／出場角色／章末鉤子） |

## 用法

```powershell
python tools/spawn.py --from <書庫>\B 書 --to <書庫>\新書\雪線 --title 雪線 --cards 3
```

目標資料夾**必須不存在或空的**，不然直接拒絕——這支程式不會覆蓋任何東西。

## 驗收（零成本，在暫存資料夾）

用《B 書》當參考書建一本《測試新書》：

| 檢查 | 結果 |
|---|---|
| 建置 | exit 0，19 個項目 |
| `project.is_book` | True |
| 資料夾 | `_範本／候選／大綱／正文／範例／設定／追蹤` |
| `shared.parse_metrics(文風.md)` | 讀得到 6 項（對白 41%、句長 17.0…） |
| 續寫合約 | 產得出來（741 字） |
| 第 1 章章綱 | 讀得到（章名「（待填）」） |
| `context.for_chapter` | 4,438 tokens，含章綱與**文風目標** |
| 指紋／DNA 副本 | 都在，代表句 10 句 |
| 檔案總數 | 37 |

也就是說：建完就能直接進「章節頁 → 寫第 1 章」，不需要先手動補任何設定檔。

## 刻意沒做的事

- **沒有生成故事**：`--from` 只提供骨架（數字），情節要 Step 3（模型）或作者自己決定。
- **沒有跑相似度護欄**：這一步產出的都是模板與數字，沒有文字內容可比對。
  護欄會接在 Step 3 的產出上（名字必須 0 命中）。
- **沒有進工作台 UI**：目前是 CLI。等工作台有「新建書」流程時再接（Step 6）。
