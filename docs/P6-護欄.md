# P6 Step 4：護欄（`similarity.check()`）

> 檢查一份新稿和來源書有多像，並且**指出哪裡**——哪一段、哪個共同片段。

## 介面

```python
from studio import similarity
r = similarity.check(new_text, source_text, lang="zh-TW", names=來源角色名)
r["ok"]        # False = 太像了
r["reasons"]   # ["6-gram 重疊 100.0%（門檻 10%）", "最長共同片段 814 字（門檻 20）", …]
r["span"]      # {"length": 814, "text": "（共同片段的前 40 字）…", "at": 1234}
r["paragraphs"]# [{"paragraph": 3, "containment": 1.0, "preview": "…"}, …]
r["names"]     # ["（來源書的角色名）", "（另一個）"]
```

CLI：

```powershell
python tools/similarity.py --source <書庫>\B 書 --new 新稿.md --lang zh-TW
# 太像 → exit 1（可直接進 CI 或流程判斷）
```

## 四道判斷（任一超標就擋）

| 判斷 | 門檻（zh-TW） | 為什麼要有 |
|---|---|---|
| 6-gram containment | 10%（自然重複 3.4%） | 整體抄了多少 |
| 最長共同片段 | 20 字（自然 0 字） | 抓「整句照搬」 |
| 沿用來源名字 | 0 個 | 沒有模糊空間 |
| 段落層 containment | 單段 ≥ 50% | **定位**：哪一段出問題 |

**為什麼要四道**：實測「換掉角色名」的抄襲，containment 仍有 0.83、最長共同 111 字。
只靠單一門檻會被改名繞過；段落層則讓作者知道該改哪一段，而不是「整篇重寫」。

## 驗收（真書，零成本）

| 案例 | containment | 最長共同 | 判定 | 指出的位置 |
|---|---|---|---|---|
| 整段照抄 1000 字 | 1.000 | 814 字 | 太像 | 第 3、4、5、9、11 段各 100% |
| 換掉名字的抄襲 | 0.834 | 111 字 | 太像 | 第 3 段 95%、第 4 段 86% |
| 抄一段＋自己寫一段 | 0.284 | 482 字 | 太像 | 只有抄的那三段 100% |
| 別的書的章節 | 0.003 | 0 字 | 可以 | — |
| 同主題、自己寫的句子 | 0.024 | 0 字 | 可以 | — |
| 同主題、自己的 61 字短文 | 0.020 | 0 字 | 可以 | — |

（「同主題自己寫」的 containment 0.024 是同義詞造成的自然重疊，距離門檻 0.10 還有 4 倍餘裕。）

## 共同片段會顯示原文

內部的比對是去標點的正規化字串，但報告會把片段對回原文（`raw_span()`），所以看到的是
「他站在船橋裡，看著雷達螢幕上…」而不是「他站船橋裡看雷達螢幕上」。
