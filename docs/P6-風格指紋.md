# P6 Step 1：風格指紋（`studio/fingerprint.py`）

> 把一本書的**寫法**抽成可攜帶的資料，給「由 A 書產生 B 書」當第一份資產。只取風格，不取故事。

## 內容

| 欄位 | 內容 |
|---|---|
| `語言` | 這本書的語言（zh-TW／en／ja） |
| `章節` | 章數、總字數、平均／中位／最短／最長章長、章長變異（標準差÷平均） |
| `文字指標` | 6 項可控制的：對白比例、平均句長、短句比例、平均段長、單句成段、每千字刪節號（跟文風閉環同一套算法） |
| `指標來源` | `文風檔` 或 `作者正文`（沒填指標時就量作者自己） |
| `代表句` | 10 句（40–120 字），跨章散佈、彼此盡量不像 |

## 三個刻意的設計

1. **不含時間戳**：同一本書跑兩次，輸出逐位元組相同（實測三本書都是 `兩次相同：True`）。指紋要能進版控、能比對。
2. **代表句把人名與勢力名遮成「某」**：句子長度不變、語感還在，但不會把來源的角色／地名／組織名帶進新書。
   實測三本書：`撞到來源名字 0 個`。地名（例如真實地名）仍可能出現在範例句裡——這是刻意的取捨，
   因為全遮會破壞句子；新書生成時另有護欄（`tools/similarity.py`）擋整段照搬。
3. **只挑「寫的時候真的能控制」的指標**：13 項裡挑 6 項。像「每千字AI味信號」這種是結果不是手段，
   放進指紋只會讓生成端不知道要怎麼做。

## 用法

```powershell
# 只看（不寫檔）
python tools/fingerprint.py --book <書庫>\B 書

# 寫進 設定/風格指紋.json
python tools/fingerprint.py --book <書庫>\B 書 --save

# 看已有的、或吐 JSON 給程式用
python tools/fingerprint.py --book <書庫>\B 書 --show
python tools/fingerprint.py --book <書庫>\B 書 --json
```

|---|---|---|---|---|---|---|
| B 書 | zh-TW | 50 | 0.17 | 10（40–71 字） | ✅ | 0 |
| C 書（日文） | ja | 138 | — | 10（39–91 字） | ✅ | 0 |
| F 書（英文） | en | 34 | — | 10（40–114 字） | ✅ | 0 |
