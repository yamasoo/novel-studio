# 安裝與設定

> 從 README 搬過來的。第一次安裝、換後端、金鑰放在哪裡、工作台設定都在這一頁。

## 需求

- Windows 10／11（macOS、Linux 也可以）
- Python 3.9 以上
- 要用 Claude Code 時：已安裝並登入的 Claude Code。skills 已內建，不必另外安裝。

## 安裝

1. 下載或 `git clone` 這個專案，放在任何地方。
2. Windows 雙擊 `start.bat`；macOS／Linux 執行 `./start.sh`。第一次會自動建立虛擬環境並安裝套件（fastapi、uvicorn、pyyaml、opencc），之後會直接啟動；更新工作台後若 `requirements.txt` 有變動，會自動補裝。
3. 瀏覽器會自動開啟 http://127.0.0.1:8765 。
4. 第一次開啟時，書架頁會請你選一個資料夾當書庫（建議「文件」底下的 `小說`，可以用「選擇…」按鈕挑資料夾），之後可以在「設定」改位置。工作台不會自動使用任何既有的資料夾。
5. 想先看看介面，按「加入示範書」。

## 設定後端

### 設定 DeepSeek

1. 到 DeepSeek 開放平台建立 API 金鑰。
2. 工作台「設定」→「AI 執行者」→ DeepSeek：貼上金鑰，或在「環境變數名稱」填 `DEEPSEEK_API_KEY` 並設定這個環境變數。
3. 按「測試連線／抓模型清單」，從清單選模型。
4. 依官方文件填「上下文長度」和價格（選填，用來估算費用）。
5. 同一家有好幾個模型（例如快又便宜的、慢但強的）：在「可用模型」按「測試連線」後點選加入，或按「新增模型」手動填。每個模型可以各自填上下文長度、最大輸出、價格、中文 token 比例，空白的沿用上面的設定，金鑰共用。之後所有選執行者的地方（右側面板、表單、整章自動流程的各步驟）都能選「DeepSeek · 某模型」。

Claude Code 預先有「預設、Sonnet、Opus、Haiku」四個選項：預設不帶 `--model`，沿用 Claude Code 本身的設定；其他三個會帶 `--model`。llama.cpp（本機）維持一個執行者一個模型。

### 設定 llama.cpp

1. 用 llama-server 啟動模型，例如：
   ```
   llama-server -m 你的模型.gguf -c 32768 -ngl 99 --port 8080
   ```
   `-c` 是上下文長度，要和工作台設定的「上下文長度」一致。顯示卡記憶體 16GB 左右時，建議先用 14B 以下的量化模型、上下文 16K～32K。
2. 工作台設定的網址維持 `http://127.0.0.1:8080/v1`，按「測試連線」。
   再按「每個中文字約幾 token」旁的「校正」：用 llama-server 的 `/tokenize` 實際算出這個模型的比例（只切字，不生成），上下文的估算會更準。
3. 本機模型的寫作品質差異很大，建議先用短章節試，再決定用在哪些任務。

LM Studio、Ollama 也是 OpenAI 相容服務，按「新增 OpenAI 相容服務」填網址即可（LM Studio 預設 `http://127.0.0.1:1234/v1`，Ollama 預設 `http://127.0.0.1:11434/v1`）。

### 金鑰存放位置

API 金鑰預設存進作業系統的金鑰庫（Windows 認證管理員、macOS 鑰匙圈），由系統加密並綁定你的登入帳號，專案資料夾裡不留金鑰檔。沒有金鑰庫可用時才存在工作台資料夾的 `secrets.json`（已列在 `.gitignore`）。舊版留下的 secrets.json，設定頁會提示一鍵搬進金鑰庫，搬完自動刪除。也可以改用環境變數。讀取順序：金鑰庫 → secrets.json → 環境變數。

## 設定

設定頁可以調整，存在 `config.json`（不進 git）：

| 項目 | 說明 |
|---|---|
| 書庫資料夾 | 每本書是裡面的一個子資料夾 |
| AI 執行者 | Claude Code、DeepSeek、llama.cpp，或自行新增 OpenAI 相容服務 |
| claude 執行檔路徑 | 留空會自動尋找；找不到時填完整路徑，例如 `C:\Users\你\.local\bin\claude.exe` |
| 模型 | Claude Code 留空用預設，可填 `opus`、`sonnet` |
| 權限模式 | 預設 `acceptEdits`：Claude 可以讀寫書目錄裡的檔案 |
| 寫稿前對帳、寫完自動核對章綱 | 可個別關閉 |
| 警示門檻 | 伏筆幾章沒出現、角色幾章沒登場就提醒（名稱含「不具名」「一次性」的角色不提醒；久未登場的角色合併成一條，可以展開） |
| 服務 | 連接埠；「重新啟動服務」按鈕 |

改了連接埠、更新了程式檔，或服務不正常時，按設定頁的「重新啟動服務」，頁面會自動重新連上（改了連接埠會自動跳到新網址）。有任務在執行時無法重新啟動。

## 專案放在「會被限制寫入」的工作區時

如果工作台是用**專案資料夾裡的 `.venv`** 啟動，而書庫在專案資料夾外，某些環境（被沙箱工具接管的工作區、
或雲端同步的資料夾）會讓這個 python 寫不進書庫，存稿時出現 `PermissionError`。解法是把虛擬環境放到外面：

```powershell
set NS_VENV=C:\Users\你\venvs\novel-studio
start.bat
```

或直接執行 `start-external.bat`（預設就是 `%USERPROFILE%\venvs\novel-studio`）。
工作台啟動時會自己檢查書庫寫不寫得進去；寫不進去會在主控台印出這段解法，不會等到存稿才失敗。
