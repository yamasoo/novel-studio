# 從大綱長設定（設定集生成）

> 目的：開新書或逆向拆書之後，設定集常常是空的；不要等寫正文才回填，也不要自己從零想。
> 這個功能把「大綱／卷綱／章綱」當依據，先生成角色、勢力、世界觀的**草稿**，看過再轉正式。

## 在哪裡

設定集頁 → 右上 **「生成設定」** → 選「我已經有大綱或卷綱」。表單欄位：

| 欄位 | 作用 |
|---|---|
| 角色／勢力／世界觀（勾選） | 這次要長哪幾類；預設全勾 |
| 參考方向（選填） | 給模型的寫作方向，例如「空中艦作戰參考二戰潛艇戰術」「世界觀偏蒸氣龐克」 |
| 參考網址（選填，每行一個） | 程式會抓網頁內文放進提示詞；最多 3 頁、每頁 6,000 字，抓不到只註明、不擋流程 |

> 它不是搜尋引擎：**不會自己上網找資料**。「參考網址」要你自己給；沒有網址時，模型只能用它的常識加上你寫的參考方向。

## 它讀什麼

- `大綱/全書大綱.md`
- 所有 `大綱/卷綱_*.md`
- 章綱清單（前 60 章：章號、章名、一句話）
- 既有 `設定/_索引.md`（避免撞名）、名詞表
- `設定/故事核心.md`、`設定/文風.md`、`設定/作者偏好.md`、狀態卡
- 你給的參考方向與網址內文

## 產出

全部寫在 **`設定/草稿/`**：一個項目一個檔、frontmatter `狀態: 草稿`。

- 角色：定位、動機、弱點、首次登場章（對齊卷綱）
- 勢力：目標、資源、和主角的關係
- 世界觀：只寫故事會用到的地理／科技／戰術，不寫百科全書
- 名字由模型原創，並要求不與既有設定撞名撞音

看完後，在同一頁按 **「草稿轉正式」** 入庫；名詞表會由那一步補。草稿轉正式會依範本整理格式、搬到對應的正式資料夾。

## 限制

- 參考網址只收 `http/https`；抓不到（403、逾時）會在提示詞裡註明「抓取失敗」，其餘照常生成。
- 一次約 1–2 次模型呼叫；章綱很多的大書會比較久。
- 生成的是「依大綱合理推測」的草稿，不是唯一答案；作者仍要挑選與修改。

## 驗證

- 假 provider：`spec_bible_from_outline` 組得出來；上下文含全書大綱、卷綱、章綱清單；任務含範圍與參考方向（已驗）。
- 真 provider：**還沒實跑**（功能剛上線）。建議先在一本新書上只勾「角色」跑一次，看草稿名字與首次登場章合不合用，再跑勢力與世界觀。
