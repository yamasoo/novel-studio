# Reports to the author

A report says only three things: **what was written, what the author must decide, and what comes next.** Speak in terms of the story, not file names, fields or step numbers. When you mention foreshadowing by ID, always attach its story tag, e.g. "foreshadowing F007 (the unsent letter)".

## After finishing one chapter

```
Chapter {N} "{title}" is done, about {words} words.
This chapter: {two or three sentences on what happened and which hook it stops on}.
{When there are new named characters or settings: "Added {who/what}, {one-line note}, already registered." Delete this line if none}
{Anything the author should watch: e.g. the lead's credit was taken by someone else, a trump card was used early, a departure from the card. Delete if none}
{One-sentence self-check result: "Checked against the settings and earlier text; no conflicts found" or "Found {what} inconsistent with earlier text and fixed it to match"}
Next: chapter {N+1} "{title}". Shall I keep going?
```

If the next chapter has no card, change the last line to: "Chapter {N+1} has no card yet. Shall I lay out the cards first?"

## After several chapters (at most three)

```
This round: chapters {N}-{M}, about {total words} words.
- Chapter {N} "{title}": {one line}
- Chapter {N+1} "{title}": {one line}
- Chapter {M} "{title}": {one line}
{New characters or settings, one per line}
{Things for the author to watch}
{One-sentence self-check result}
Next: chapter {M+1}. Shall I continue?
```

## Needs the author's decision (new things at the "ask the author first" tier)

```
Partway through chapter {N}, {an extra element appeared / I wanted to add something and have not written it}; I need you to decide: {what it is, in story terms}.
It affects {which later plot or settled arrangement}.
1. {Keep / add} it, and I adjust the later outline to match
2. {Cut / do not add} it and write to the original card
I suggest {1/2}: {one-line reason}.
This chapter is not finished yet; I will wait for your decision before going on.
```

## Length far off

```
Chapter {N} is written, {shorter/longer} than target by about {difference} words (target about {target}, now {actual}). {One-line reason, e.g. "the card's events were done by here; stretching would pad"}
How would you like to handle it?
1. Keep this length (recommended)
2. I adjust the card or the length target and rewrite
3. {When short: "Add a scene: {concrete suggestion}" / when long: "I trim to the target length"}
```

## Cannot write, stopping

```
Chapter {N} cannot be written yet: {what is missing in plain words, e.g. "this chapter has no card" or "tracking has not been updated since the last chapter"}.
I suggest {one action}. Is that OK?
```
