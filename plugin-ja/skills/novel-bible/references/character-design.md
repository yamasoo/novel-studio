# 人物設計の方法

人物を生成したり補ったりするときに従います。目的は「場面を支えられること」であって、履歴書を埋めることではありません。

## 1. 先に役割を問い、そのあとで資料

人物ごとに、まず答える：**この人は物語の中で何をするのか。**

よくある役割の枠：
- **主人公**：読者が自分を重ねる相手。物語のエンジン。
- **敵対者**：主人公が望むものを得るのを妨げる。単に悪いのではなく、本人なりの筋の通った目標があるのが最善。
- **鏡**：主人公が選ばなかった道を行った人。主人公の選択が何を失わせるかを読者に見せる。
- **師／資源の提供者**：主人公に能力、情報、機会を与える。たいてい自分の計算がある。
- **想い人**：主人公を感情的に引き、恋の線を動かす。
- **踏み台**：主人公に追い越される、または頭を下げさせられ、主人公の成長を示す。連載ではよくあるが、納得できる動機は必要で、ただ愚かなだけであってはいけない。
- **攪乱者**：驚きを生み、計画を乱し、変数を加える。

二人の人物に同じ役割の枠を与えない。さもないと一方が飾りになる。一人が二つの役割を持ってもよい。

## 2. 人物を立たせる四つの欄

資料のうち最も重要なのがこの四つで、あとは細部：

1. **望み**：妨げられうる具体的な目標。「強くなりたい」は漠然としすぎる。「組合の試験で上位十人に入り、奪われた枠を取り戻したい」なら場面にできる。
2. **恐れ**：何がこの人に誤った選択をさせるか。
3. **欠点**：本人に代償を払わせ、読者を心配させる性格上の弱さ。欠点のない人物には成長の余地がない。
4. **譲れない線**：この人が決してしないこと。譲れない線は一貫性の錨で、それを破る姿を書くときは、十分な圧と代償が必要。

## 3. 声カード（全員が同じ話し方にならないように）

主要人物は、それぞれ次に答えられるようにする：
- **文の長さ**：饒舌か寡黙か。完全な文か、数語か。
- **語域**：洗練、粗野、専門語、方言、ネットスラング。
- **一人称と語尾**：私、僕、俺、あたし、自分、名前呼び。です・ます調か、だ・である調か、語尾の癖は何か。日本語では、一人称と語尾が声を分ける最大の手がかり。
- **いつもの圧のかけ方**：理屈、冷笑、過去を持ち出す、哀れを装う、沈黙、いきなり手が出る。
- **立場の違う相手に対して**：目上、同等、目下で、話し方はどう違うか。
- **口癖や決まった型**：あれば書く。無理に作らない。口癖は稀にしておく。頻繁だと安っぽいレッテルになる。

試し方：会話の中の話し手の名前を隠す。読者は誰か当てられるか。

## 4. 外見：目印だけ残す

証明写真のような描写（身長、髪の色、目の色、服、すべて列挙）は書かない。読者が覚えられ、筋に使える特徴を一つか二つ残す：古い傷、いつもはめている手袋、かすかに引きずる足、話す前の咳払い。

## 5. 関係には温度と向きが要る

関係の欄は、「師弟」や「敵」より多くを語る：
- **温度**：信頼、依存、警戒、利用し合い、敵意 …
- **向き**：関係は良くなっているか、悪くなっているか。
- **言わないこと**：双方が何を隠しているか。

## 6. 脇役をまとめて生成する

作者が「脇役を N 人出して」と言ったとき：
1. まず用途を確かめる：筋のどこにいて、どんな役割を担うか。不明なら尋ねる。
2. 一人ごとに書くのは「一行の役割 ＋ 望み ＋ 欠点 ＋ 声カード 2、3 行 ＋ 主人公との関係」だけ。長い生い立ちは書かない。
3. 互いが違うようにあえて作る：身分、話し方、立場を引き離す。
4. すべて `設定/草稿/` に入れ、作者が選べるようにする。
5. 音や字面が似た名前、既存の人物とあまりに近い名前（名詞表と人物フォルダで確かめる）は避ける。言語モデルが出しすぎる定番の名前も避ける。

## 7. よくある欠点

- 資料は埋まっているのに、葛藤になる項目が一つもない。
- 人物が全員、賢く、雄弁で、理性的。
- 悪役に自分の目標がなく、主人公を妨げるためだけに存在する。
- 資料には「冷たい」とあるのに、本文では登場のたびに人を気遣っている。資料は行動に落ちなければならず、表の中だけに生きていてはいけない。
