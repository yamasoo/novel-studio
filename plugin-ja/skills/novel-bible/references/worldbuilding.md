# 世界観の作り方

## 1. 物語が使うものだけを作る

世界観は筋に仕える。設定ごとに問う：**筋のどこでこれを使うか。** 答えられなければ、まだ作らないか、草稿に一行だけ残す。

書き出しが必要とするのは、たいてい数文：主人公がどこにいて、ここでの決まりがどうなっていて、その決まりの中で主人公がどこに立っているか。ほかの細部は、筋がそこに来るまで待つ。

## 2. 散文ではなく規則を書く

設定ファイルは、本文を「確かめる」ために使えなければならないので、並べた規則として書く：

- 悪い例：「この世界の魔術体系は奥深く多様で、多くの階梯があり、それぞれに個性がある。」
- 良い例：
  - 魔術は九つの階梯：体、脈、核 …
  - 各階梯に初期・中期・後期の段階がある
  - 一つの段階をまたぐ戦い：技や道具があれば可能
  - 一つの階梯をまるごとまたぐ戦い：大きな代償（寿命を焼く、道具を壊す）を払わない限りほぼ不可能

## 3. どの能力にも代償と限界が要る

代償のない能力は葛藤を壊す。主人公がすべて解決できるなら、読者は緊張しない。能力や反則ごとに、はっきりさせる：
- **発動条件**：どんな条件で使えるか。
- **代償**：使うと何を失うか。（体力、寿命、記憶、借り、身分が露見する危険）
- **限界**：一日に何回か。何には効かないか。
- **成長の道筋**：どう強くなるか。各段階で何が解禁されるか。

反則級の能力の規則は「先に作者に聞く」水準：AI が自分で足したり変えたりしてはいけない。

## 4. よくある項目と、答えるべきこと

| 項目 | 少なくとも答えること |
|---|---|
| 力の体系 | どう階級が分かれるか。どう上がるか。階梯をまたぐ条件は。資源はどこから来るか |
| 地理 | 物語は主にどこで起きるか。場所同士はどれだけ離れ、どう行き来するか |
| 社会構造 | 誰が力を持つか。階級はどう分かれるか。主人公はどこにいるか |
| 経済 | 何が取引されるか。普通の人の月収は。主人公は金に困っているか |
| 歴史 | どの過去の出来事が、いまの筋に影響するか |
| 宗教／信仰 | 人々は何を信じているか。それが人物の選択をどう形づくるか |

経済の錨（値段、収入）は、本文に一度書くと変えにくいので、慎重に決めて、世界観ファイルに書いておく。

## 5. 読者がいつ知るかを記す

重要な設定ごとに「読者がいつ知るか」を書く。これは本文が何を書いてよいかに直接影響する：まだ開示されていない設定は、人物が知っていてもよいが、地の文が説明してはいけない。

## 6. よくある欠点

- 書き出しで世界観の長い講義をして、筋が止まる。
- 主人公の境遇と関係のない巨大な設定。
- 規則が矛盾する（第 3 章では階梯をまたげないと言い、第 30 章では主人公が代償なしに二つまたぐ）。
- 思いつきで書いた経済の数字が、後で合わなくなる。

## 7. 分類とタグ

世界観ファイルの frontmatter には `分類` が必要で、次の11項目のいずれか一つだけを使う（値は中文のまま書く。日本語訳は参考）：

力量體系（力の体系）、地理與氣候（地理と気候）、歷史與年表（歴史と年表）、社會與政治（社会と政治）、經濟與物資（経済と物資）、宗教信仰（宗教と信仰）、文化與風俗（文化と風俗）、科技原理（科学技術の原理）、載具與兵器（乗り物と兵器）、生態與資源（生態と資源）、其他（その他）

- 「このファイルが何に答えるか」で決める。仕組み（能力がどう働くか）→ 力量體系、具体的な物（ある船、ある武器）→ 載具與兵器、制度や法的地位 → 社會與政治。
- どうしても当てはまらない場合だけ「其他」を使う。少数のファイルのために新しい分類を作らない。
- `標籤` は任意。複数可で、下位の種類を示す。例：`[艦船]`、`[武器]`、`[外星]`。
