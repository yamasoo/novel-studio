# 章綱の書き方

章綱は、本文の唯一の筋の設計図です。novel-write はこれに沿って書くので、章綱は「持っていれば間違った方向に書けない」ところまで書き、ただし本文のようには書かないでください。

## 1. 四つの問い（毎章必須）

1. **この章で、主人公は何をしようとするか。**
2. **それを妨げるのは誰か、何か。**
3. **この章の後、状況はどうなっているか。**
4. **読者が先を読みたくなる理由は何か。**

問い 3 に答えられない、または答えが「何も変わらない」なら、その章は削るか、まとめるか、圧縮する。

## 2. 場面の最小構造

どの場面にも、少なくとも**目標、障害、変化**が要る。変化のない場面（情報だけ、世間話だけ）は、削るか、別の場面にまとめるか、小さな変化を与える。

## 3. 情節點の書き方

- 起きる順に、一行に一つ挙げる。
- 「何が起こるか」を書く。「どう書くか」は書かない：
  - 良い：「恭介が人前で婚約を破棄する。澪は泣かず、契約書の印は誰のものかと尋ねる」
  - 悪い：「澪の目に冷たいものがよぎり、口元がかすかな嘲りに歪んだ…」（これは本文であって章綱ではない）
- 肝心の選択とその結果を固め、過程の細部は本文が遊べるように残す。
- 一字一句そのまま出す必要がある台詞（誓い、手紙の中身、システムの表示）は、情節點の後に「原文：…」を足す。
- 一章に 3～6 点が最も多い。8 点を超えるなら、詰め込みすぎのことが多く、二章に分けることを考える。

## 4. 役割と目標の感情

各章に主な役割を一つ与える：
- **進行**：本筋が一歩進む
- **カタルシス**：逆転、反撃、得るもの
- **緊張**：恋や関係の引き合い
- **開示**：新しい情報、新しい手がかり、真相の一角
- **仕込み**：後の爆発の条件を整える
- **つなぎ**：場面転換、休息、日常（続けすぎない）

続けて、読了後に読者に起こしたい主な感情を挙げる（満足、緊張、好奇心、切なさ、甘さ、もどかしさ）。三章続けて同じ感情なら、調整を考える。

## 5. 章末の引き

各章の止める場所を計画する。引きの種類：

| 種類 | 説明 | 例 |
|---|---|---|
| 未解決の問い | 読者が答えを求めずにいられない問いを投げる | 封筒の中は白紙一枚だったのに、裏には母だけの印が押されていた |
| 危機 | 人物が危険にさらされる | 外の足音が止まった |
| 逆転 | 読者がいま信じたことを壊す | 彼女を助けた男の袖口には、嘉山家の紋があった |
| 新しい目標 | 次の段階の明確な方向を与える | 三日後に組合の試験が開き、上位十人が書庫に入れる |
| 軽い予告 | 大げさにせず、次の場面を軽く指す | 「行こう」と彼は桟橋の先へ向いた |
| 感情の余韻 | 重い感情の場面の後、最後にもう一拍、浸らせる | （山場の次の章に合う） |

規則：
- **毎章が危機ではない**：同じ引きを繰り返すと読者は麻痺し、作為が見える。入れ替え、強いものと柔らかいものを交互にする。
- **引きは約束**：次の章がそれを受け止めなければならない。受け止められない引きは、読者の信頼を使い果たす。
- **すべての糸を結ばない**：章末には、少なくとも一本、解決していないものを残す。
- 圧の高い章や進行の章では引きを強く。つなぎの章は、段階の目標か小さな謎だけでよい。

## 6. 伏線の操作

章綱に書く：
- この章で**新しく仕込む**伏線（仮の番号を付け、書いた後に正式に登録する）
- **進める、または軽く触れる**伏線
- **回収する**伏線（重要な伏線の回収は「先に作者に聞く」。章綱に入れる前に作者の同意を確かめる）

## 7. 禁止事項

この章で**起きてはいけない**ことを書く。特に：
- まだ明かせない真相
- まだ会えない、気づけない人物
- まだ使えない能力や切り札

これは novel-write のためのガードレールで、AI が盛り上がる場面を書くために後の展開を早く使ってしまうのを防ぐ。

## 8. 章綱をまとめて並べる

一つの劇情單元（5～15 章）ずつが最善。終わったら：
1. 單元の感情曲線を確かめる：圧、解放、單元末の小さな山場。
2. 引きの種類が変化しているか確かめる。
3. 各章の四つの問いの問い 3 を確かめ、毎章状況が変わるようにする。
4. 伏線を確かめる：軽く触れるべきものが予定されているか。
5. 作者には單元の概観（一章一行：題 ＋ 一言 ＋ 役割）を見せ、全部の章綱を詳しく一度には見せない。
