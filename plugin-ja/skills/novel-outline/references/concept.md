# 故事核心の診断

大綱を書く前に、そのアイデアが想定の長さを支えられるか確かめます。アイデアが最小の骨格に収まらないときは、急いで章を並べないでください。

## 1. 最小の骨格（五つの問い）

1. **主人公は誰か。** 一文で：身分 ＋ 境遇。
2. **何を望むか。** 妨げられうる、進み具合が読者に見える、具体的な目標。
3. **何が妨げるか。** 敵、制度、本人の欠点、環境。
4. **読者はなぜ、主人公の勝利（あるいは苦闘）を見たいのか。** 共感の点：受けた仕打ち、不公平、憧れ、対比。
5. **物語はどう回り続けるか。** 物語の仕組み（下を見る）。

五つのうち答えられないものがあれば、先に作者と話し合う。

## 2. 売り：読者が本当に消費しているもの

連載の読者は、繰り返し得られる一種の感情の満足のためについてくる。この本が主に提供するものを、一つから三つ言えるようにする：

| 売りの種類 | 読者が得るもの | 典型の技法 |
|---|---|---|
| 逆転／見返し | 爽快感 | 見下される → 能力を見せる → 周囲の反応 |
| 隠れた強さ | 期待 ＋ 爽快感 | 主人公は過小評価され、読者は真相を知り、圧が溜まって爆発する |
| 成長の段階 | 達成感 | はっきりした階級、各段階での目に見える収穫 |
| 恋の緊張 | ときめき、焦がれ | 近づきと障害が交互に来る、すれ違いと和解 |
| 謎／サスペンス | 好奇心、知的満足 | 手がかりを前もって公平に置き、「そうだったのか」で明かす |
| 建設／開拓 | 安心、蓄積 | 無から有へ、数と規模の成長 |
| 身分の対比 | 驚き | 隠された身分が一層ずつ明かされ、他人の認識が裏返る |

売りが拍を決める：カタルシスの物語には密な解放が、謎には等間隔の手がかりが、恋には押し引きが必要。

## 3. 物語の仕組み

物語の仕組みは、「しばらくごとに新しい葛藤を自然に生み出す」機構のこと。仕組みのない長編は、二十章、三十章あたりで、することが尽きてくる。

良い仕組みには、たいてい次の特徴がある：
- **繰り返せる**：同じ機構が、違う場面、違う敵に合う。
- **段階が上がる**：繰り返すたびに、賭けるものや舞台が上がる。
- **本筋に結ぶ**：各回の結果が、本筋を一歩進める。

例：
- 「割符の層をひとつ開くたびに、より強い追手が現れ、過去の断片が明らかになる」：繰り返せ、上がり、本筋に結ぶ。
- 「主人公は強く、あちこちで悪人を倒す」：繰り返せるが、上がらず、本筋にも結ばず、すぐ飽きられる。

## 4. 読者との約束

読者との約束は、書き出しで読者にした約束で、その後も守るもの：
- **ジャンルの約束**：甘い恋とうたえば、最後まで暗い話にはできない。
- **主人公の約束**：書き出しで主人公が賢く見えたなら、筋の都合で愚かになってはいけない。
- **拍の約束**：書き出しがカタルシスで密なら、突然十章も解放がない、ということはできない。

約束は `設定/故事核心.md` に挙げる。大綱と章綱を書くとき、約束の破りがないか照らす。

## 5. 長さの判断

| アイデアの特徴 | 向く長さ |
|---|---|
| 中心の逆転が一つ、関係の変化が一つ | 短編（1 万字以下） |
| 成長や復讐の一周があり、舞台を広げる必要が少ない | 中編（3～8 万字） |
| 成長の段階があり、舞台が層ごとに広がり、交互に進める支線がいくつもある | 長編（10 万字以上） |

作者が長編を望んでいるのに、アイデアが中編しか支えないなら、正直にそう言い、延ばす案（成長の段階を足す、支線を足す、舞台を広げる）を出して、作者に決めてもらう。

## 6. 診断の出力形式

診断の後、作者に次の項目を、各一、二文で示す：
1. 最小の骨格（五つの問いへの答え）
2. 主な売り
3. 物語の仕組みと、どこまで走れるかの判断
4. おすすめの長さ
5. 現在の不足と提案（多くて三つ、重要な順）
