# 書き出しと最初の三章

最初の三章で、読者が残るかどうかが決まります。第 1～3 章の章綱を計画するときの必読です。

## 1. 書き出しが、いつまでに何を届けるか

よくある目安で、ジャンルに合わせて調整する：

| 進み具合 | 届けるもの |
|---|---|
| 最初の 200～400 字 | 引き：異常、危機、葛藤、あるいは強い人物の境遇。「何かが起きている」「この人は面白い」と読者に思わせる |
| 最初の 2,000～3,500 字 | 売りが見える：この本が主にどんな楽しみを与えるかが読者に分かる |
| 最初の三章（約 6,000～10,000 字） | 読者が、主人公が誰で、どんな厄介事にいて、この本の売りが何で、次に何を見たいかを知っている |

## 2. 第 1 章（最初の 2,500 字ほど）が築くべきこと

1. **主人公**と、読者が気にかける理由（受けた仕打ち、境遇、対比、可笑しみ、粘り強さ）。
2. **世界の基本の決まり**：この章が必要とするものだけを、数文で。
3. **少しの謎**：読者がもう少し知りたくなる何か。
4. **核心の葛藤の影**：まだ十分に展開しなくても、読者が圧を感じる。
5. **勢い**：終わりが、次の章を開く理由を与える。

まず読者に主人公を気にかけさせ、背景はそのあとに。気にかければ、読者はもっと知りたくなる。

## 3. 最初の三章のよくある進め方

特別な強みを持つ成長物語の場合：
- **第 1 章**：事件を起こす。主人公が窮地に落ち（婚約を破棄される、陥れられる、家を追い出される）、強みへの導入を仕込む。
- **第 2 章**：重要人物を出すか、強みを明らかにして、読者に逆転の見込みを見せる。
- **第 3 章**：主人公が強みを使って最初の収穫を得る（小さな見返し、成長の第一歩）。「この本はこうして届け続ける」を確立する。

ほかのジャンルでの対応：
- **ミステリー**：第 1 章 異常な出来事 → 第 2 章 捜査が壁にぶつかる、または二つ目の異常 → 第 3 章 最初の重要な手がかりと、高まる賭け。
- **恋愛**：第 1 章 二人が緊張をはらんで出会う → 第 2 章 接触を余儀なくされる → 第 3 章 最初のときめき、または最初のはっきりした障害。

## 4. 書き出しのよくある欠点

- **背景が多すぎる**：世界、家の歴史、力の体系の紹介が長く続く。直し方：主人公のいまの境遇が必要とするものだけを残し、あとは筋がそこに来たときに語る。
- **動いて、止まって説明する**：戦いで始まり、途中で三段落の背景が入る。直し方：説明を砕き、動きと会話の隙間に忍ばせる。
- **人物を一度に出し切る**：主人公の登場に、外見、性格、経歴をすべて説明する。直し方：一章に一面か二面だけを見せる。
- **スロー・バーン**：最初の三章が日常ばかりで葛藤がない。連載は、既定ではスロー・バーンではない。作者が確信しているなら、せめてサスペンスか人物の魅力で支える。
- **主体性のない主人公**：主人公が出来事に押されているだけ。直し方：厄介事の中で、少なくとも一つの選択を主人公にさせる。
- **葛藤を物理の問題として書く**：「どう川を渡るか」だけがあり、「なぜこの一歩が彼らにそれほど重要か」がない。葛藤には感情の重みが要る。

## 5. 書き出し計画のチェックリスト

第 1～3 章の章綱を並べた後、一項目ずつ確認する：
- [ ] 第 1 章の早いところに引きがある
- [ ] 第 1 章に、読者が主人公を気にかける理由がある
- [ ] 最初の三章のうちに売りが見える
- [ ] 最初の三章のうちに、主人公が少なくとも一つの能動的な選択をする
- [ ] 最初の三章のうちに、少なくとも一つの小さな感情の解放がある
- [ ] どの章も、先を読む理由で終わる
- [ ] 世界の説明は、いま必要なものに限られている
