# 長編の構造と拍

## 1. 三つの層

| 層 | 長さ（長編の場合） | 役割 |
|---|---|---|
| 巻 | 5～12 万字 | 大きな舞台：設定、敵、目標が比較的固定 |
| 劇情單元 | 5～15 章 | 完結した小さな周期：発端 → 葛藤 → 小さな山場 → 結果 |
| 章 | 2,000～4,000 字 | 進行の単位：状況が少なくとも少しは変わる |

計画は常に大から小へ：全書 → 巻 → 單元 → 章。卷綱がないまま章綱を並べると、支線の暴走、設定の肥大、章末の力不足が起きやすい。

## 2. 圧と解放

連載の基本の感情の周期は**仕込み → 圧 → 爆発**：
- **仕込み**：主人公が何を持ち、何を望み、何が妨げているかを読者に知らせる。
- **圧**：主人公が挫折し、見下され、不利な立場に置かれる。読者は一緒に息をひそめる。
- **爆発**：主人公が覆し、勝ち、得る。読者が溜めていた息が一気に解かれる。

圧は爆発に向けて高まるが、長すぎてはいけない。経験上：
- 各章は、それ自体が小さな感情の単位であるのが理想：少しの圧、少しの緩み、あるいは少なくとも明確な期待。毎日追う読者は一章ずつ読むので、一章まるごと息を詰めさせると離れる。
- 劇情單元は、小さな山場で終わる。
- 巻は、大きな山場で終わり、卷契約を果たす。
- 三章を超えて圧が続いたら問う：読者はまだ耐えられるか。差し込める小さな解放はあるか。

## 3. カタルシスの設計

### 見返しの三つの形
- **公然型**：公の場で直接やり返し、相手がその場で倒れる。
- **静かな型**：主人公が間接的に得る。相手は後で気づくか、負けたことを一生知らない。
- **誤解型**：周囲が主人公の行為を読み違え、もっと大きな理由を想像して、可笑しみを生む。

### 隠れた強さの四つの条件
1. 主人公の能力が過小評価されている。
2. そのため、主人公は見下されたり、からかわれたりする。
3. 読者は真相を知っている（期待の源）。
4. 爆発が来る。しかも満足のいく形で来なければならない。

### カタルシスを安っぽくしない
- **仕込みが識別できる**：カタルシスの前に、主人公が何を準備し、何を払ったか読者に見える。
- **反応の連鎖**：主人公が動いた後、その場の人々の違う反応（衝撃、抵抗、悔い、見直し）を書く。快感は他人の認識が裏返ることから来る。
- **層を重ねられる**：一回の見返しの中に、一つか二つの逆転を重ねる（勝ったと思った → 相手に備えがあった → 主人公はそれにも備えていた）と、密度が増す。
- **主人公が結果を勝ち取る**：偶然の勝利や、他人から手渡された勝利は平板に感じる。
- **得たものが代償なしに奪われないように**：主人公が勝ったのに、得たものが年長者、組織、偶然に簡単に持っていかれると、読者はもどかしい。奪われるなら、見返りを与えるか、主人公が取り返すための伏線を残す。

## 4. 期待

期待は、読者に「いま満足していなくても待つ」ようにさせるもの：
- 何かが必ず起こると読者は知っているが、いつ、どう起こるかは知らない。
- 主人公が、読者は知っていて敵は知らない切り札を持っている。
- 明確なカウントダウン（三日後に試験、一か月後に結婚式）。

期待は**利子を払わなければならない**：長く開いたままのものは、途中で小さな支払い（少しの進展、手がかり）をし、新しい期待を重ねて、読者に宙づりが長すぎると感じさせない。

## 5. 成長の段階と舞台の拡大

長編は、主人公の舞台を一層ずつ広げなければならない（家 → 町 → 組合 → 世界全体）。舞台が変わるたびに：
- 古い敵に決着が要る（倒す、和解する、味方になる）。
- 新しい舞台に、新しい決まり、新しい敵、新しい天井が要る。
- 主人公は、新しい舞台の早いうちに、たいていまた低い立場に置かれる。これが新しい見返しの余地を生む。

## 6. 伏線の配置

大綱を計画するとき、重要な伏線の仕込みと回収の両方を配置する：
- 重要な伏線は少なくとも三回触れる。毎回違う状況で、強調しない。
- 仕込みと回収の間に距離を置いて、読者が意識して忘れるようにする。そうすれば回収が「そういうことだったのか」と着地する。
- 伏線を仕込むとき、意味を説明しない。
- 回収では、読者が「気づくべきだった」と感じるようにし、「分かるわけがない」と感じさせない。
- 十章以上触れられていない重要な伏線は、読者（や作者）が完全に忘れないよう、軽く触れる。

## 7. 中盤をまとめる

長編は中盤で最もぶれる。計画のときに確認する：
- どの劇情單元も、本筋を進めるか、本筋のための資源を整えているか。
- どの支線にも、はっきりした終点があるか。
- 長く放置された人物や伏線がないか。
- 新しい設定が、筋に使われないまま積み上がっていないか。
