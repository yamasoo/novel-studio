# 作者への報告

報告が言うのは三つだけです：**何を書いたか、作者が何を決めるべきか、次は何か。** ファイル名、フィールド名、手順番号ではなく、物語の言葉で話します。伏線を番号で挙げるときは、必ず物語上の呼び名を添えます。例：「伏線 F007（出されなかった手紙）」。

## 一章を書き終えたとき

```
第{N}章「{題名}」を書き終えました。約 {字数} 字です。
この章：{何が起き、どの引きで止まるかを二、三文で}。
{名前のある新しい人物や設定があるとき：「{誰／何}を追加し、{一行の説明}、登録済みです。」なければこの行を削除}
{作者に見てほしい点：例えば主人公の手柄が他人に取られた、切り札を早く使った、章綱から外れた、など。なければ削除}
{自己点検の結果を一文で：「設定と前の本文に照らして確認し、矛盾は見つかりませんでした」または「{何}が前の本文と合っていなかったので直しました」}
次は：第{N+1}章「{題名}」。続けましょうか。
```

次の章に章綱がなければ、最後の行を「第{N+1}章の章綱はまだありません。先に章綱を並べましょうか」にする。

## 複数章を書いたとき（最大 3 章）

```
今回：第{N}～{M}章、約 {合計字数} 字です。
- 第{N}章「{題名}」：{一行}
- 第{N+1}章「{題名}」：{一行}
- 第{M}章「{題名}」：{一行}
{新しい人物や設定を一行ずつ}
{作者に見てほしい点}
{自己点検の結果を一文で}
次は：第{M+1}章。続けましょうか。
```

## 作者の判断が必要なとき（「先に作者に聞く」段階の新しいもの）

```
第{N}章の途中で、{余計な要素が出てきた／足したくなったが書いていない}ものがあり、判断をお願いしたいです：{物語の言葉で、それが何か}。
影響するのは {どの後続の筋や確定した段取り} です。
1. {残す／足す}。後の大綱をそれに合わせて調整する
2. {削る／足さない}。元の章綱どおりに書く
{1／2}をおすすめします：{一行の理由}。
この章はまだ書き終えていません。判断をいただいてから先へ進みます。
```

## 長さが大きくずれたとき

```
第{N}章を書きましたが、目標より約 {差} 字{短い／長い}です（目標 約 {目標}、現在 {実際}）。{一行の理由。例：「章綱の出来事はここで終わっており、引き延ばすと水増しになります」}
どう扱いましょうか。
1. この長さのままにする（おすすめ）
2. 章綱か長さの目標を調整して書き直す
3. {短いとき：「場面を足す：{具体案}」／長いとき：「目標の長さまで削る」}
```

## 書けなくて止まるとき

```
第{N}章はまだ書けません：{足りないものを平易な言葉で。例：「この章に章綱がありません」「前の章から追蹤が更新されていません」}。
{一つの行動}をおすすめします。よろしいですか。
```
