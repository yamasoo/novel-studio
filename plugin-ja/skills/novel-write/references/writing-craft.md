# 本文を書くための技法

本文を書く前に一度読みます（同じ会話の中で読み直す必要はありません）。これは一般的な技法で、この本の `設定/文風.md` と衝突したら、文風が優先です。

## 1. 場面：どの場面も何かを変える

場面 ＝ **目標 → 障害 → 変化**。
- この場面で誰が何を望むのかが読者に分かるように入る。
- 障害を具体的にする：人、一言、扉、決まり。
- 終わりまでに状況が変わっている：関係、情報、境遇、あるいは目標。

場面を書いたら問う：これを削ったら物語は何を失うか。「何も失わない」なら、作り直す。

## 2. 感情：示す。告げない

AI 臭が最も出るところです。感情は、読者に言い聞かせるのではなく、感じさせます。

**着地させる三つの方法：**
1. **行動**：感情の下で人物がすること。「緊張していた」ではなく、湯呑みを三度回して、一口も飲まなかった。
2. **物**：感情を具体的な物に結ぶ。「母が恋しかった」ではなく、洗いざらして色の抜けたエプロンが、誰も触れないまま扉の裏に掛かっている。
3. **反応の連鎖**：刺激 → 最初の身体の反応 → 考えや選択 → 行動。間を飛ばして結論に跳ばない。

**判断：**
- 気持ちを平叙で一行言うことは、最も必要なところに置けばかえって効く。直接の叙述を全面的に禁じると、気取った文章になる。
- 大きな感情は重い描写を意味しない。痛いほど、たいてい文は短く、形容は少なくなる。
- あらゆる感情に微表情（口元が引きつる、目に光が揺れる、瞳孔が開く）を付けない。微表情は薬味であり、主菜ではない。

## 3. 会話

### すべての台詞が少なくとも一つのことをする
筋を進める、人物を見せる、緊張を作る、情報を渡す（その情報は葛藤の中に埋める）。世間話や、情報を渡すだけの台詞は、削るか書き直す。

### 言外の意味
現実の人は、本心をそのまま言うことが少ない。人物が何かを隠していると、会話に緊張が生まれる。

表と真実の差を読者に見せる五つの経路：
1. **言葉**：表明する立場（偽りでもよい）。
2. **身体**：無意識の小さな動き。
3. **生理**：脈、湿った手のひら、詰まった喉（視点人物だけが感じられる）。
4. **内なる声**：視点人物の本当の反応。
5. **声**：急に変わる速さ、大きさ、間。

読者がこれらの経路の差を見られれば、語り手が説明する必要はない。言外の意味は、場面の中の他の人物が気づかなくても、読者には読み取れなければならない。

### 全員が違う声で話す
- 人物の声カード（`設定/角色/` の「說話方式」）に従って書く。
- 試し方：話し手の名前を隠す。読者は誰の台詞か当てられるか。
- 誰もが雄弁なわけではない：口ごもる人、違う問いに答える人、言いさして止める人がいる。
- すべての問いに答えが返るわけではない：かわす、話題を変える、問い返すほうが、まっすぐ答えるより面白い。

### 発話の動詞と言い回し
- 「言った」が最良の発話動詞。「唸った」「低く告げた」「冷ややかに呟いた」に置き換えない。
- 誰が話しているか明らかなときは、「言った」さえ省く。仕草の一文が帰属を担える。
- 台詞ごとに「〜と静かに」「〜と淡々と」のような副詞を付けない。
- 日本語は主語や発話の動詞を省ける。省けるところは省き、台詞の癖と語尾で話し手を分ける（敬語の度合い、一人称、語尾、方言）。

## 4. 場面転換

読者が最も迷うのは場面の変わり目です。転換のたびに次を明らかにする：
- **時間**：どれくらい経ったか。（「三十分後」「翌朝」）
- **空間**：いまどこか。段落いっぱいの説明ではなく、具体的な感覚の細部一つで位置を示す。
- **感情の引き継ぎ**：前の場面の気持ちが、新しい場面でどう続き、どう変わるか。場面が変わった瞬間に、人物は直前のことを忘れない。
- **視点**：視点人物が変わるなら、最初の一文で、誰の目かを読者に分からせる。

テンポよく切るのはかまわないが、因果、人物の状態、関係は切らない。

## 5. カタルシスの場面を書く

1. **仕込みが識別できる**：爆発の前に、主人公の準備や、押さえ込まれている圧力が読者に見える。
2. **一撃は鮮やかに**：肝心の動作は、短く、正確に、絵が浮かぶように書く。形容詞を積んで「迫力」にしない。
3. **反応の連鎖が快感の本体**：その場の人々の違う反応を書く：呆然とする人、信じない人、悔やむ人、見直す人。快感は、他人の認識が裏返るところから生まれる。
4. **結果を与える**：決着の後で、主人公は実際に何を得たか（評判、資源、立場、情報）。
5. **読者の代わりに喝采しない**：「その瞬間、全員が言葉を失った」のようなまとめの一行を入れない。反応に語らせる。

## 6. 拍と文

- **長い文と短い文を交互に。** 全部が長いと息が詰まり、全部が短いと電報のようになる。緊張するところは短く、ゆるむところは長めに。
- **文末を変える。** 「〜た。〜た。〜た。」と同じ語尾が三つ以上続くと単調になる。体言止め、倒置、会話、現在形の挿入を混ぜる。ただし、変化をつけるためだけに文を崩さない。
- **段落に息をさせる。** スマホでは長い段落は読者を遠ざける。通常の地の文は 3～5 行で改行し、重要な一行は単独で立ててよいが、毎行ではない。
- **描写は行動に従う。** 背景は、人物が動きの途中で気づき、それがいまの状況に関わるときに最もよく効く。どの場面にも移せる描写は水増し。
- **比喩は正確に、少なく。** 最良のものは人物自身の暮らしから出る（人を肉の部位のように見積もる肉屋、人を帳簿として見る帳簿係）。ありきたりな比喩（潮のように、刃のように、運命の歯車）は、削れるなら削る。
- **漢字とかなの配分。** 地の文の硬さは、漢語と漢字の密度で決まる。文風が指定する硬さに合わせ、必要以上に難しい熟語を並べない。

## 7. 開示の境界

- `追蹤/時間線.md` の「讀者目前知道」を守る。語り手は、まだ明かされていない真相を漏らしてはならず、「彼はまだ知らなかった」と予告を忍ばせてもいけない。
- 限定視点では、視点人物が見て、聞いて、考えられることだけを書く。
- 章綱の禁止事項を守る。
- 解禁される前に、能力や切り札を使わない。

## 8. 書いた後に確認する AI 臭の三種

検査ツールでは捉えられないので、段落ごとに読み直す：

1. **読者に要点を教える**：段落の意味を締めくくる、整った対句、警句、三点並べ。
   → 削る。それがなくて読者が付いてこられないなら、示し方が弱いので、行動や細部を足しに戻る。
2. **語り手が出てきて説明する**：人物の気持ちをまとめる（「彼女はようやく理解した」）、動機を説明する（「彼がそうしたのは…からだった」）、章綱の結論を本文にそのまま書く。
   → 人物の行動、台詞、物に変えて、読者に見せる。
3. **教訓めいた・振り返り・予告めいた章末**：「長い夜になりそうだった」「彼女はまだ知らなかった。さらに大きな嵐が来ることを」「この瞬間から、すべてが変わった」。
   → 具体的な像、行動、台詞一つで止める。

あわせて確認する：
- **工房の言葉の漏れ**：本文に「第 X 章」「前の章」「伏線」「章綱」「読者」などがあってはならない（物語にそういうものが本当にある場合を除く）。
- **章綱の写し**：章綱の情節點はあなたへの指示であり、できあがった文ではない。章綱の文を言い換えてつなぐのではなく、場面として演出する。
- **日本語の定型句**：思わず息を呑んだ／胸が締め付けられた／言葉を失った／ふと〜／どこか〜／まるで〜のようだった／静寂が訪れた／〜という名の（飾りとして）／〜せずにはいられなかった／時が止まったかのようだった／心臓が跳ねた。それぞれ、この場面だけの具体的なものに置き換える。
- **「のだった」の連発**：説明の「〜のだった」「〜わけだった」を重ねない。事実は事実として言い切る。
- **同じ型の反復**：「〜ではなく、〜だった」の反射的な使用、体言止めの連続、「〜と思った。〜と感じた」の連続。

## 9. 章末

- **変化**で止める。要約で止めない。
- 具体的な像、行動、台詞で止める。
- 章綱が計画した引きの種類に従う。章綱が何も言っていなければ、章の役割で選ぶ（novel-outline の章末鉤子を参照：未解決の問い、危機、逆転、新しい目標、軽い予告、感情の余韻）。
- 次の章の最初の一拍が、この終わりを受け止められなければならない。
