# 角色設計方法

生成或補完角色時照這份做。重點是「能寫出戲」，不是填滿一張履歷表。

## 一、先問功能，再問人設

每個角色先回答：**這個人在故事裡負責什麼？**

常見功能位：
- **主角**：讀者代入的對象，故事的引擎。
- **對手**：阻止主角得到想要的東西。最好有自己合理的目標，而不是單純壞。
- **鏡子**：走了主角沒走的路，讓讀者看見主角的選擇有什麼代價。
- **導師／資源提供者**：給主角能力、資訊或機會，通常也有自己的算計。
- **情感對象**：與主角產生情感拉扯，帶動感情線。
- **墊腳石**：被主角超越或打臉，讓讀者看見主角的成長。網文常見，但仍要有可信的動機，不能只是蠢。
- **攪局者**：製造意外、打亂計畫，增加變數。

同一個功能位不要塞兩個角色，否則其中一個會變成擺設。一個角色可以兼兩個功能。

## 二、讓角色立起來的四個欄位

人設表裡最重要的是這四欄，其他都是細節：

1. **想要**：具體、可被阻止的目標。「想變強」太空泛；「想在宗門大比進前十，拿回被奪走的名額」可以寫成戲。
2. **害怕**：會讓他做出錯誤選擇的東西。
3. **缺陷**：讓他吃虧、讓讀者擔心的性格弱點。沒有缺陷的角色沒有成長空間。
4. **底線**：他絕對不做的事。底線是角色一致性的錨點：寫到他要破底線時，必須有足夠的壓力和代價。

## 三、聲音卡（防止所有人講話一個樣）

每個主要角色要能回答：
- **句子長短**：話多還是話少？愛講完整句還是只丟幾個字？
- **用詞層次**：文雅、粗口、行話、方言、網路用語？
- **慣用的施壓方式**：講道理、冷笑、翻舊帳、裝可憐、沉默、直接動手？
- **對不同身分的人**：對上位者、平輩、下位者，說話方式有什麼差別？
- **口頭禪或標誌性句式**：有就寫，沒有不要硬加。口頭禪要少，出現太頻繁會變成廉價標籤。

檢驗方式：把對白的說話者名字遮住，讀者能不能猜出是誰？

## 四、外貌只留辨識點

不要寫證件照式描述（身高、髮色、眼睛顏色、穿什麼全列一遍）。只留一兩個讀者記得住、最好還能用在劇情裡的特徵：一道舊疤、總是戴著的手套、走路微跛、說話前會先清嗓子。

## 五、關係要有溫度與方向

關係欄不只寫「師徒」「仇人」，要寫：
- **溫度**：信任、依賴、警戒、利用、敵視……
- **方向**：這段關係正在變好還是變壞？
- **未說出口的東西**：雙方各自隱瞞了什麼？

## 六、批量生成配角時

作者說「幫我生成 N 個配角」時：
1. 先確認用途：要放在哪個劇情段落、負責什麼功能？不清楚就問。
2. 每個配角只寫「一句話功能＋想要＋缺陷＋聲音卡兩三條＋和主角的關係」，不寫長篇背景。
3. 刻意讓他們彼此不同：身分、說話方式、立場要拉開距離。
4. 全部放 `設定/草稿/`，讓作者挑。
5. 名字避免撞音、撞字，也避免和既有角色太像（查名詞表與角色資料夾）。

## 七、常見毛病

- 人設寫得很滿，但沒有一條能變成衝突。
- 所有角色都很聰明、都很會說話、都很理性。
- 反派沒有自己的目標，只為了阻擋主角而存在。
- 設定寫了「冷漠」，正文卻每次出場都在照顧人。人設要落在行為裡，不能只存在於設定表。
