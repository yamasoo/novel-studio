# 世界觀設計方法

## 一、只建故事用得到的

世界觀是為劇情服務的。每建一條設定先問：**哪一段劇情會用到它？** 答不出來的，先不建，或只留一句話放草稿。

開篇需要的世界觀通常只有幾句話：主角身處什麼地方、這裡的遊戲規則是什麼、主角在這個規則裡處於什麼位置。其他細節等劇情碰到時再揭露。

## 二、寫成規則，不寫成散文

設定檔要能拿來「檢查」正文，所以寫成條列規則：

- 不好：「這個世界的修煉體系博大精深，分為許多境界，每個境界都有其獨特之處。」
- 好：
  - 修為分九境：煉體、通脈、凝丹……
  - 每境分前、中、後三期
  - 越一個小期戰鬥：有可能，靠功法或法寶
  - 越一整境戰鬥：幾乎不可能，除非付出重大代價（燃燒壽元、法寶損毀）

## 三、能力一定要有代價與限制

沒有代價的能力會讓衝突失效：主角什麼都能解決，讀者就不緊張了。每條能力或金手指要寫清楚：
- **觸發條件**：什麼情況下能用？
- **代價**：用了會失去什麼？（體力、壽命、記憶、人情、暴露身分的風險）
- **限制**：一天幾次？對什麼無效？
- **成長路線**：之後怎麼變強？每一階段解鎖什麼？

金手指的規則屬於「先問作者」的層級：AI 不能自己新增或修改。

## 四、常見主題與要回答的問題

| 主題 | 至少要回答 |
|---|---|
| 力量體系 | 怎麼分級？怎麼升級？越級的條件？資源從哪來？ |
| 地理 | 故事主要發生在哪幾個地點？它們之間多遠、怎麼移動？ |
| 社會結構 | 誰有權力？階級怎麼分？主角在哪一層？ |
| 經濟 | 用什麼交易？一般人一個月賺多少？主角缺錢嗎？ |
| 歷史 | 哪些過去的事件會影響現在的劇情？ |
| 宗教／信仰 | 人們相信什麼？這會怎麼影響角色的選擇？ |

經濟錨點（物價、收入）一旦寫進正文就很難改，建立時要謹慎，並登記在世界觀檔。

## 五、標註揭露時機

每條重要設定註明「讀者何時知道」。這會直接影響正文能寫什麼：還沒揭露的設定，正文中的角色可以知道，但敘述不能直接講破。

## 六、常見毛病

- 開篇大段介紹世界觀，劇情遲遲不動。
- 設定很龐大，但跟主角的處境無關。
- 規則前後矛盾（第三章說不能越境，第三十章主角輕鬆越兩境還沒有代價）。
- 經濟數字隨手寫，後面對不上。
