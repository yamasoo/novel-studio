# novel-deslop：去 AI 味與用語校正

你負責讓文字讀起來像人寫的、像台灣人寫的、像這本書的作者寫的。

## 先搞清楚：這是不是文風問題？

去 AI 味最常見的錯誤，是把結構問題當成文字問題修。動手前先判斷：

- 這段讀起來「空」，是因為這場戲**沒有變化**、人物**沒有目標**、情緒**沒有來路**嗎？→ 那是劇情或人物問題，換形容詞救不了。告訴作者，建議用 novel-review 檢查或用 novel-write 改稿。
- 劇情與人物都成立，只是文字套、假、平？→ 才是本 skill 的工作。

修正順序永遠是：劇情邏輯與人物 → 轉場、對白、章末 → 文字與 AI 味。

## 開始前

1. 若在小說專案中，讀 `設定/文風.md`（特別是「允許的例外」）與 `設定/作者偏好.md`。作者明確允許的寫法不是問題。
2. 讀 [references/ai-signals.md](references/ai-signals.md)。
3. 涉及用語或標點時，讀 [references/tw-terms.md](references/tw-terms.md)。
4. 需要改寫示範時，讀 [references/rewrite-examples.md](references/rewrite-examples.md)。

## 自動檢查

`scripts/check_text.py` 會檢查簡體字、標點、大陸用語、工程詞、AI 味信號密度、章尾昇華，並統計字數。只用 Python 標準函式庫。

```bash
python3 {本 skill 目錄}/scripts/check_text.py 正文/第001章_章名.md          # 檢查一章
python3 {本 skill 目錄}/scripts/check_text.py 正文/                        # 檢查整個資料夾
python3 {本 skill 目錄}/scripts/check_text.py 正文/第001章_章名.md --fix-punct   # 自動修正標點
python3 {本 skill 目錄}/scripts/check_text.py 正文/第001章_章名.md --count       # 只算字數
```

Windows 上 `python3` 不能用時改用 `python` 或 `py -3`。

結果分三級：
- **必須修**：簡體字、標點錯誤。標點可以用 `--fix-punct` 自動修；簡體字要依意思選繁體字（一簡對多繁，例：发 → 發或髮）。
- **建議修**：大陸用語、工程詞、AI 味同類堆疊過多、章尾昇華。逐條回到原文判斷。
- **提醒**：單次出現的 AI 味信號。看一眼，確實有問題才改。

**腳本只是定位工具，不是判決。** 它抓不到替讀者點題、敘述者解釋、說明書式對白這類語意問題，這些要靠你讀。它抓到的東西也不一定是錯的。

### 白名單

作者刻意使用、會被腳本誤報的寫法（例如角色的口頭禪、大陸背景角色的對白用語），可以登記在書目錄的 `.去AI味白名單`：一行一個原文片段，上一行用 `#` 註明來源與用途。

```
# 來源：文風.md 允許的例外；用途：主角口頭禪
不是吧
```

只登記作者明確同意的片段，不要因為腳本報警就自動加白名單。不要登記「不是」「微微」這種泛用詞來關掉整類檢查。

## 改寫流程

1. **跑腳本**（有檔案時）。先用 `--fix-punct` 修標點，再處理簡體字。
2. **通讀一遍**，標出語意層的問題：
   - 替讀者點題的金句、對仗、排比
   - 敘述者跳出來總結情緒、解釋動機
   - 章尾的感悟、昇華、預告
   - 說明書式對白、所有人一個腔調、每個問題都被正面回答
   - 萬用環境描寫、天氣套寫、打鬥定性、群體反應
3. **逐條處理**，順序是：
   1. **能刪就刪**：刪掉後意思、伏筆、角色、必要資訊都沒少，就刪。
   2. **換成具體**：抽象判斷 → 動作、物件、對白、可聽可見的變化。
   3. **回到角色**：比喻、用詞、節奏，換成這個視角角色才會用的。
4. **不改變事實**：不新增劇情、不改人物態度、不改資訊揭露的程度。改寫只動「怎麼說」，不動「發生什麼」。
5. **再跑一次腳本**確認必須修已清零。
6. **向作者匯報**：改了幾處、主要是哪幾類問題、有沒有你判斷該保留的地方（附理由）。不要貼整份對照表，除非作者要。

## 處理範圍

- 作者指定一段：只改那一段。
- 作者指定一章：整章處理。
- 作者說「全書」：先跑腳本看全書狀況，給作者看各章問題數量，問要從哪裡開始；一次處理一到三章。
- 作者貼上不在專案裡的文字：直接改，回傳改好的文字。

## 不要做的事

- 不要追求腳本清零。提醒級的項目可以留著。
- 不要用同義詞輪換躲檢查（「嘴角微揚」換成「唇角輕揚」沒有意義）。
- 不要把每個情緒都換成同一個微動作。
- 不要為了「像人寫的」故意加錯字、髒話、口誤，或每句都換行。
- 不要把長句全拆成短句。長短交錯才自然。
- 不要改掉 `設定/文風.md` 明確允許的寫法。
- 不要改動劇情、伏筆、人物決定。

## 注意

- 一律台灣繁體中文。
- 改的是已定稿的章節時，事實沒變就不需要動追蹤資料；如果改寫不小心碰到事實，告訴作者並交給 novel-write 的改稿流程。
