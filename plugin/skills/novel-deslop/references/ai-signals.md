# AI 味信號索引

> 這裡列的是**需要回到上下文判斷的信號**，不是出現就錯的禁詞。孤立出現通常沒事；跨場景機械重複、成片堆疊、或只是在替情緒貼標籤時，才需要改。
> 不要追求清零，也不要用同義詞輪換來躲檢查。
> 分類架構參考 oh-story-claudecode（MIT 授權）的 AI 味信號表，內容以台灣繁體中文重寫並增補；「罐頭反應」「短句轟炸」「換詞循環」「破折號密度」「句長過勻」參考 Raymondhou0917/speak-human-tw（MIT 授權）改寫成小說版。

## 一、AI 味從哪裡來

1. **譯制腔**：大型語言模型的訓練資料以英文為主，寫出來的中文常帶翻譯味：代名詞多、主詞完整、從句長、形容詞前置堆疊。
2. **安全的平均值**：總是挑最常見、最不會錯的搭配，所以每個人都「嘴角微揚」、每片天空都「陰沉沉的」。
3. **過度工整**：句子長度平均、排比整齊、每段都先總結再解釋。
4. **不敢留白**：怕讀者看不懂，所以每個情緒都要說出名字，每個動機都要解釋，每個場景都要點題。

改的方向：**具體、有落差、有留白、像這個角色會說的話。**

## 二、句式與結構信號

| 信號 | 常見形式 | 回到上下文問 |
|---|---|---|
| 否定翻轉 | 「不是 A，而是 B」「沒有 X，沒有 Y，只有 Z」 | 是不是先立一個沒人在意的靶子，再宣布結論？真的在糾正誤會時可以留 |
| 工整排比 | 跨段的「不是……也不是……只是……」；「有的……有的……」；三個以上同結構短句連發 | 是不是在重複同一個意思？排比也可以是角色的語氣 |
| 萬用狀語 | 「，帶著一絲……」「聲音不大，卻帶著……」「語氣平靜無波」 | 是不是只貼了抽象態度，沒有可辨的內容？ |
| 解釋結論 | 「這意味著」「之所以……是因為」「他終於明白」「她這才意識到」「這是最好的選擇」 | 是不是重複了讀者已經懂的事，或把該寫的過程概括掉？ |
| 意義膨脹 | 「意義深遠」「前途無量」「一切都將改變」「這就是……」 | 有沒有具體影響？還是只是放大音量？ |
| 預告與昇華 | 「命運的齒輪開始轉動」「從這一刻起」「屬於他的反擊才剛剛開始」「他不知道的是」「殊不知」「多年以後」 | 是不是越過了資訊揭露邊界？是不是在替讀者喊感想？ |
| 點破潛台詞 | 「笑得恰到好處」「誰都看得出他在撒謊」「演得真好」 | 是不是替讀者把偽裝提前說破？角色帶偏見的判斷和敘述者斷言要分開 |
| 告知心理 | 「他知道……」「她感到……」「他意識到……」「顯得有些……」「散發著一股……的氣息」 | 是不是只在貼標籤？準確直寫、有來源的判斷可以留 |
| 電報體 | 連續孤立短句；「抬手、拿起、放下、轉身」的動作清單 | 是不是丟了動作的方向和連結？ |
| 公文腔 | 「與此同時」「事實上」「綜上所述」「進一步」「從而」「基於」「落實」 | 和角色、年代、場合的語氣合不合？ |
| 代名詞先行 | 「他，林家二少爺，青雲宗外門弟子，……」 | 是不是英文式同位語堆疊？ |
| 轉折模板 | 「眼神裡有 A，但更多的是 B」 | 情緒能不能用一個動作呈現？ |

## 三、套詞信號

這些詞孤立出現沒問題，**同一章出現多次、或每個情緒都配一個**時要改：

| 類別 | 例詞 |
|---|---|
| 弱化裝飾 | 微微、淡淡、緩緩、輕輕、一絲、一抹、些許、幾分、隱約、微不可察 |
| 通用表情 | 嘴角勾起、嘴角微揚、眼中閃過、眉頭微皺、瞳孔一縮、瞳孔微縮、指節泛白、深吸一口氣 |
| 通用心理 | 心頭一震、心中一動、心下了然、心中暗道、不由得、心中湧起一股暖流 |
| 空泛定性 | 不容置疑、不容置喙、毫無疑問、顯而易見、前所未有、深邃、凜冽、生人勿近 |
| 萬用比喻 | 仿佛／彷彿……一般、如潮水般、像一把刀、像命運的齒輪、淬了毒、如沐春風 |
| 自動過渡 | 映入眼簾、只見、此時此刻、不由自主、話鋒一轉、取而代之的是 |
| 語境敏感 | 突然、猛地、瞬間、死死地、沉聲道、淡淡地說 |

「她感到」「意識到」「彷彿」「突然」都可能是準確的寫法。判斷標準是：**拿掉這個詞，或換成具體的動作／細節，會不會更好？**

## 四、段落層級的信號

| 信號 | 例 | 要問 |
|---|---|---|
| 萬用環境 | 陽光透過窗簾的縫隙灑進來，在地板上投下斑駁的光影，空氣中瀰漫著淡淡的花香 | 這段搬到任何一本書都成立嗎？和此刻的行動、情緒有關嗎？ |
| 天氣套寫 | 天空陰沉沉的，烏雲密布，彷彿隨時都會下起傾盆大雨 | 有沒有重複堆疊同一種氣氛？天氣有沒有影響行動？ |
| 打鬥定性 | 他的拳頭如疾風驟雨般猛烈，每一擊都蘊含著不容置疑的力量 | 攻防過程、失誤、後果在哪裡？ |
| 哲理收尾 | 他站在窗前望著遠方，終於明白了：有時候，放手才是最好的選擇 | 是不是在替讀者總結？ |
| 翻頁收尾 | 這一刻，一切都變了。她知道，她的人生將翻開新的一頁 | 能不能停在具體的畫面上？ |
| 群體反應 | 所有人都震驚了，不敢相信自己的耳朵 | 能不能寫兩三個人各自不同的反應？ |
| 完整解釋 | 「其實我這樣做是有原因的，因為當時的情況非常複雜……」 | 真實的人會這樣完整解釋嗎？ |
| 同一動作重拍 | 連續三段都在寫同一個握筆、發抖的瞬間 | 是必要的慢鏡頭，還是在湊字數？ |
| 罐頭反應 | 他愣了一下。她沉默了幾秒。空氣彷彿凝固了。 | 刪掉這句，讀者會少知道什麼嗎？沒有就刪；有的話換成這個人此刻會做的具體動作 |
| 短句轟炸 | 門開了。風很冷。他走進去。燈滅了。 | 每一句都在推進嗎？還是只是在用斷句硬造氣勢？留下最有力的一兩句 |
| 換詞循環 | 同一章裡「林遠」「林公子」「那個少年」「林家長子」輪流出現 | 讀者分得清是同一個人嗎？固定一兩種稱呼，其他用代名詞 |

### 節奏與密度（檢查腳本會算）

- **破折號**：敘述中每 400 字最多一次。多數可以改成逗號、句號或拆句；對白裡的打斷、改口不算。
- **句長過勻**：連續好幾句長度差不多，讀起來像機器排的。打散成長短交錯：一句長的帶情境，接一句短的落動作。
- **短句與破折號是文風的一部分時**（例如冷硬派），寫進 `設定/文風.md` 的「允許的例外」，去 AI 味時保留。

## 五、對白的 AI 味

- **每個人都很會說話**：句子完整、邏輯清楚、有禮貌、會總結。
- **每個問題都被正面回答**：沒有迴避、沒有誤解、沒有答非所問。
- **說明書式對白**：角色互相講述雙方都知道的事，只是為了讓讀者知道。
- **一個腔調**：遮住名字分不出是誰在說話。
- **情緒全靠標記**：「他憤怒地說」「她委屈地說」。

## 六、改的時候別矯枉過正

- 不要把每個情緒詞都換成同一個微動作（全書都在「攥拳」「垂眼」）。
- 不要為了「不 AI」故意加錯字、髒話、口誤，或每句都換行。
- 不要把作者在 `設定/文風.md` 明確允許的寫法改掉。
- 不要為了去詞而刪掉有功能的資訊（修飾語可能承擔區分、承接、動作條件）。
- 長句、比喻、排比本身不是錯，問題在於它們是不是空的。

## 七、改法的三個方向

1. **能刪就刪**：刪掉後意思沒少、伏筆沒少、角色沒少，就刪。
2. **換成具體**：抽象判斷 → 動作、物件、對白、可聽可見的變化。
3. **回到角色**：比喻、用詞、句子節奏，換成這個視角角色才會用的。
