# 兩岸用語與標點

本書使用台灣繁體中文。以下是寫小說時最容易混進來的中國大陸用語。

## 使用前提

- **故事背景決定用語。** 古代、仙俠、架空世界本來就不該出現現代用語；故事背景設在中國大陸、角色是大陸人時，角色的**對白**可以保留大陸用語當作身分特徵，但**敘述**仍用台灣用語。這類例外寫進 `設定/文風.md` 的「允許的例外」。
- **「建議改」**：台灣幾乎不這樣說，出現在敘述中通常是誤用。
- **「看情況」**：台灣也有人用，或意思依上下文而定，要判斷。

## 二、看情況

| 大陸用語 | 台灣常用 | 判斷 |
|---|---|---|
| 地鐵 | 捷運 | 台北、高雄說捷運；其他國家城市說地鐵可以 |
| 摩托車 | 機車 | 台灣日常說機車；重型機車可說重機 |
| 土豆 | 馬鈴薯 | 台灣的「土豆」是花生 |
| 數據 | 資料、數據 | 統計數字可用數據；電腦資料用資料 |

## 三、標點

| 用途 | 台灣用法 | 不要用 |
|---|---|---|
| 引號 | 「」，引號內再引用『』 | “” ‘’ "" |
| 刪節號 | ……（兩個，六點） | ... 、。。。、… 單個 |
| 破折號 | ——（兩個） | — 單個、-- |
| 書名號 | 《》，篇名〈〉 | |
| 間隔號 | ‧ 或 · | |
| 一般標點 | 全形：，。？！：；（） | 中文句子裡的半形 , . ? ! : ; ( ) |

- 對話結尾的句號放在引號內：「我走了。」
- 引號內的話被打斷：「我——」
- 數字與英文可以用半形，前後不用強制加空格（依本書文風決定）。

## 四、容易被簡體輸入帶進來的字

語音輸入或簡繁轉換有時會留下錯字，常見的有：
- 一簡對多繁：发（發／髮）、干（乾／幹／干）、后（後／后）、里（裡／里）、面（麵／面）、只（隻／只）、台（臺／台／檯／颱）、松（鬆／松）、斗（鬥／斗）、谷（穀／谷）、准（準／准）、才（才／纔）、表（錶／表）、制（製／制）、钟（鐘／鍾）
- 轉換後要人工確認意思：「頭发」應為「頭髮」、「乾杯」不是「幹杯」、「後面」不是「后面」、「這裡」不是「這里」。
