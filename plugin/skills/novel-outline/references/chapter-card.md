# 章綱寫法

章綱是正文的唯一劇情藍圖。novel-write 會照章綱寫，所以章綱要寫到「拿著它就能寫，不會寫錯方向」，但不要寫成正文。

## 一、本章四問（每章必填）

1. **主角這章想做什麼？**
2. **誰或什麼阻止他？**
3. **這章結束後局面變成什麼？**
4. **讀者為什麼還要往下看？**

第 3 題答不出來，或答案是「沒什麼變化」，這章就該刪、併或壓縮。

## 二、場景最小結構

每場戲至少要有：**目標、阻礙、變化**。沒有變化的場景（只是交代資訊、只是日常閒聊），要嘛刪掉，要嘛併進別的場景，要嘛加入一個小變化。

## 三、情節點怎麼寫

- 照發生順序列，一點一行。
- 寫「發生什麼」，不寫「怎麼寫」：
  - 好：「沈既白當眾提出退婚，林晚沒哭，反問他婚書上的印是誰蓋的」
  - 不好：「林晚眼中閃過一絲冷意，嘴角勾起一抹淡淡的嘲諷……」（這是正文，不是章綱）
- 關鍵的選擇與結果要寫死；過程細節留給正文發揮。
- 如果有一定要原文出現的句子（誓言、信件內容、系統提示），在情節點後註明「原句：……」。
- 一章 3～6 個情節點最常見。超過 8 個通常是塞太多，考慮拆成兩章。

## 四、本章功能與目標情緒

每章標一個主功能：
- **推進**：主線往前一步
- **爽點**：打臉、逆襲、收穫
- **拉扯**：感情或人際關係的推拉
- **揭露**：新資訊、新線索、真相的一角
- **鋪墊**：為後面的爆發埋設條件
- **過場**：轉換場景、休整、日常（不能連續太多章）

再標讀者看完的主要感受（痛快、緊張、好奇、心疼、甜、憋屈）。連續三章感受都一樣時，考慮調整。

## 五、章末鉤子

每章都要規劃結尾停在哪裡。鉤子類型：

| 類型 | 說明 | 例 |
|---|---|---|
| 未解問題 | 拋出讀者一定想知道答案的問題 | 信封裡只有一張空白紙，背面卻蓋著母親的私印 |
| 危機 | 角色陷入險境 | 門外的腳步停了 |
| 反轉 | 打破讀者剛建立的認知 | 救她的人，袖口繡著沈家的徽記 |
| 新目標 | 給出下一階段的明確方向 | 三日後的宗門大比，前十名可以進藏經閣 |
| 輕預告 | 不大張旗鼓，只輕輕指向下一場 | 「走吧。」他轉身往村口去 |
| 情緒餘韻 | 一場重情緒戲之後，留下讓人回味的一拍 | （適合高潮之後的章節） |

規則：
- **不要每章都是危機**：連續用同一種鉤子會讓讀者麻木，也顯得刻意。輪替使用，強弱交錯。
- **鉤子是承諾**：下一章必須接住。接不住的鉤子會消耗讀者信任。
- **不要把所有線都收乾淨**：章末至少留一條沒解決的線。
- 高壓或推進章鉤子要強；過場章留一個階段目標或小懸念就夠了。

## 六、伏筆操作

章綱裡寫明：
- 本章**新埋**哪些伏筆（給暫定編號，寫完後正式登記）
- 本章**推進或輕觸**哪些伏筆
- 本章**回收**哪些伏筆（回收重要伏筆屬於「先問作者」，排進章綱前要確認作者同意）

## 七、禁止事項

寫下這章**不能**發生的事，特別是：
- 還不能揭露的真相
- 還不能見面或相認的角色
- 還不能使用的能力或底牌

這是給 novel-write 的安全欄，可以防止 AI 為了寫得精彩而提前透支後面的劇情。

## 八、批量排章綱

一次排一個劇情單元（5～15 章）最適合。排完後：
1. 檢查單元內的情緒曲線：有壓、有放、單元末有小高潮。
2. 檢查鉤子類型有沒有變化。
3. 檢查每章四問的第 3 題，確定每章局面都有變。
4. 檢查伏筆：該輕觸的有沒有排到。
5. 給作者看單元總覽（一章一行：章名＋一句話＋功能），而不是一次丟出全部章綱細節。
