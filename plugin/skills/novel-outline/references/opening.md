# 開篇與黃金三章

網文的前三章決定讀者會不會留下來。規劃第 1～3 章章綱時必讀。

## 一、開篇要在什麼時候交出什麼

以下是常見的參考節點，依題材調整：

| 進度 | 要交出的東西 |
|---|---|
| 前 300～500 字 | 一個抓手：異常、危機、衝突、或強烈的人物處境。讀者要知道「出事了」或「這人有意思」 |
| 前 1500～3000 字 | 賣點露頭：讀者看得出這本書主要提供什麼樂趣 |
| 前三章（約 6000～10000 字） | 讀者知道：主角是誰、遇到什麼麻煩、這本書的賣點、接下來想看什麼 |

## 二、第一章（約前 2500 字）要確立的事

1. **主角**是誰，以及讓讀者在乎他的理由（委屈、處境、反差、好笑、堅持）。
2. **世界的基本規則**：只講這一章用得到的，幾句話帶過。
3. **一點神秘感**：讀者想多知道一點的東西。
4. **核心衝突**的影子：就算還沒全面展開，也要讓讀者感覺到壓力。
5. **推動力**：結尾要有讓人點下一章的理由。

先讓讀者在乎主角，再給背景。讀者在乎之後，自然想知道更多。

## 三、黃金三章的常見推進方式

以有金手指的成長文為例：
- **第一章**：製造事件。主角陷入困境（被退婚、被陷害、被逐出家門），同時埋下金手指的引子。
- **第二章**：引入關鍵人物或揭開金手指，讓讀者看到翻盤的可能。
- **第三章**：主角用金手指拿到第一筆收穫（小小的打臉、第一次成長），確立「這本書會這樣爽下去」。

其他題材的對應：
- **懸疑**：第一章出現異常事件 → 第二章調查碰壁或出現第二個異常 → 第三章給出第一條關鍵線索並升高賭注。
- **感情**：第一章兩人以有張力的方式相遇 → 第二章被迫產生交集 → 第三章出現第一次心動或第一次明確的阻礙。

## 四、開篇常見毛病

- **背景說明太多**：開篇大段介紹世界觀、家族史、修煉體系。改法：只留主角此刻處境需要的資訊，其他等劇情碰到再講。
- **先動作再停下來解釋**：一場打鬥開場，打到一半插入三段背景說明。改法：解釋拆碎，塞進動作與對白的縫隙裡。
- **一次把人設講完**：主角出場就把外貌、性格、身世全部交代。改法：每章只露一兩面。
- **慢熱**：前三章都在日常，沒有衝突。網文預設不慢熱；作者確定要慢熱時，至少要用懸念或人物魅力撐住。
- **主角沒有主動性**：主角只是被事件推著走。改法：在困境中讓主角做出至少一個選擇。
- **把衝突寫成物理問題**：只寫「怎麼過河」，沒寫「為什麼這一步對他很重要」。衝突要帶情感重量。

## 五、開篇規劃檢查表

排完第 1～3 章章綱後逐項確認：
- [ ] 第一章前段有抓手
- [ ] 讀者在第一章就有在乎主角的理由
- [ ] 賣點在前三章內露出
- [ ] 前三章內主角至少做出一次主動選擇
- [ ] 前三章內至少有一次小的情緒釋放
- [ ] 每章結尾都有往下看的理由
- [ ] 世界觀說明只限此刻需要的部分
