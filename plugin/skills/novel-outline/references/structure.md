# 長篇結構與節奏

## 一、三層結構

| 層級 | 篇幅（以 300 萬字以下長篇為例） | 作用 |
|---|---|---|
| 卷 | 15～40 萬字 | 一個大階段：舞台、對手、目標都相對固定 |
| 劇情單元 | 5～15 章 | 一個完整的小循環：起點→衝突→小高潮→結果 |
| 章 | 2000～4000 字 | 一個推進單位：局面至少要變一點 |

規劃順序永遠是由大到小：全書 → 卷 → 單元 → 章。沒有卷綱就排章綱，很容易支線亂長、設定膨脹、章末疲軟。

## 二、壓抑與釋放

網文的基本情緒循環是 **鋪墊 → 壓抑 → 爆發**：
- **鋪墊**：讓讀者知道主角有什麼、想要什麼、被什麼擋住。
- **壓抑**：主角受挫、被輕視、處境變差，讀者跟著憋氣。
- **爆發**：主角翻盤、打臉、拿到收穫，讀者的悶氣一次釋放。

壓抑是為了爆發蓄力，但不能太久。經驗上：
- 每章最好自成一個小的情緒單位：有一點壓、有一點鬆，或至少留下明確的期待。日更讀者每天只看一章，一整章都在憋會流失讀者。
- 一個劇情單元末要有一次小高潮。
- 一卷末要有大高潮，並兌現卷契約。
- 連續壓抑超過三章，要問自己：讀者還撐得住嗎？有沒有小的釋放可以穿插？

## 三、爽點的設計

### 打臉的三種形態
- **明爽**：當面反擊，對方當場吃癟。
- **暗爽**：主角間接得利，對方事後才發現、或根本不知道自己輸了。
- **誤會爽**：旁人誤解主角的行為，腦補出更厲害的解釋，產生喜劇效果。

### 扮豬吃虎的四個條件
1. 主角的實力被低估。
2. 主角因此被輕視或嘲笑。
3. 讀者知道真相（這是期待感的來源）。
4. 爆發一定會來，而且要來得夠痛快。

### 讓爽點不廉價
- **鋪墊要能指認**：爽點之前，讀者要看得到主角為此做過什麼準備、付出什麼。
- **反應鏈**：主角出手後，寫在場其他人的不同反應（震驚、不服、後悔、重新評估），爽感來自旁人認知的翻轉。
- **可以疊層**：一次打臉裡疊一兩層反轉（以為贏了→對方還有後手→主角早有準備），密度更高。
- **主角要靠自己掙到結果**：靠巧合、靠別人送上門的勝利不痛快。
- **收益不能被無代價地拿走**：主角贏了，成果卻被長輩、機構、巧合輕易奪走，讀者會很憋。真要奪走，要給交換或留下主角能拿回的伏筆。

## 四、期待感

期待感是讓讀者「現在不爽也願意等」的東西：
- 讀者知道某件事一定會發生，只是不知道何時、怎麼發生。
- 主角手上有底牌，讀者知道、對手不知道。
- 一個明確的倒數（三天後大比、一個月後婚禮）。

期待感要**付利息**：長期懸而未決的東西，中途要給一點小兌現（一點進展、一點線索），再留新期待，讀者才不會覺得被吊太久。

## 五、升級台階與舞台擴大

長篇要讓主角的舞台一層層變大（家族 → 城市 → 宗門 → 天下）。每換一層舞台：
- 舊對手要有交代（打敗、和解、轉為盟友）。
- 新舞台要有新規則、新對手、新的天花板。
- 主角在新舞台初期通常要重新處於下位，才有新的逆襲空間。

## 六、伏筆的排程

規劃大綱時，把重要伏筆的「埋設」與「回收」都排進去：
- 重要伏筆至少要提及三次，每次在不同情境、不刻意強調。
- 埋設與回收之間要有距離，讓讀者在意識上忘記，回收時才會有「原來如此」。
- 伏筆的意義不要在埋設時說破。
- 回收時，目標是讓讀者覺得「我早該看出來」，而不是「這誰知道」。
- 超過十章沒有任何提及的重要伏筆，要安排一次輕觸，避免讀者完全忘記或作者自己忘記。

## 七、中段不散的方法

長篇最容易在中段發散。規劃時檢查：
- 每個劇情單元是否都在推進主線，或為主線準備資源？
- 支線是否有明確的結束點？
- 有沒有某個角色或伏筆被晾太久？
- 新設定是不是越加越多，卻沒有被劇情用到？
