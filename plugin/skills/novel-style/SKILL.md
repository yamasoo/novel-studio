# novel-style：文風設計與分析

文風檔是寫正文時優先級最高的規則（只低於作者當下的要求）。你的工作是讓它**具體到能照著寫**，而且**短到 AI 記得住**。

## 開始前

1. 完整讀 [references/style-dimensions.md](references/style-dimensions.md)——十三個面向、範例段落的要求、長度建議。
2. 作者提到類型時，讀 [references/genre-cues.md](references/genre-cues.md) 對應的段落。
3. 範本在 `../novel-setup/templates/文風.md`（專案裡是 `_範本/文風.md`）。新檔照範本的章節順序寫；舊檔保留作者原本的章節，缺的再補。
4. 判斷檔案位置：
   - 在某本書裡 → `設定/文風.md`
   - 作者說「共用」「存進書庫」「以後別本書也要用」→ 書庫的 `_共用/文風/<名稱>.md`（書目錄的上一層），frontmatter 加 `名稱: <名稱>`，標題寫 `# 文風：<名稱>`
   - 不確定 → 問一句

## 寫規則的原則

- **可執行**：每一條都要能拿來檢查一段文字有沒有做到。「節奏明快」不行；「動作戲一句一個動作，十字以內」可以。
- **給範圍與情境，不給死數字**：數字讓 AI 機械湊數。精確的數字放在「文字指標（程式統計）」那一節，由程式量。
- **寫深五到八項就好**：只寫這個文風**和一般寫法不一樣**的地方。通用規則本來就會做的事（「句子通順」「少錯字」）不要寫。
- **禁忌要附替代做法**：只說「不要寫 X」，AI 會寫成 X 的同義詞。寫成「不寫 X，改寫 Y」。
- **三分清楚**：建議做法（傾向）／本書禁忌（一律不准）／允許的例外（刻意要用，附用途）。
- **參考作品只學特徵**：拆成可描述的特點寫進規則。**不抄原文，不用參考作品的人名、地名、專有名詞、招牌台詞**，範例段落也一樣。作者自己的書裡用到參考作品的角色（同人）是作者的事，但文風檔本身仍以特徵描述為主。
- **範例段落最重要**：至少三段有場景標籤的範例（【對白】【動作】【描寫】【情緒】【轉場】挑最能代表的），每段後面一句「我喜歡它哪裡」指出示範了哪條規則；可加一段【反例】附「為什麼不行」。範例必須原創，或用作者自己的文字。
- **長度**：整份 1500～3000 字（不含指標表）。超過就刪通用規則，或把重複的規則合併。
- 全部用台灣繁體中文。作者用簡體輸入時照意思轉成繁體。

## 四種工作

### A. 從描述設計（作者只給類型、感覺、參考作品）

1. 讀 genre-cues.md 對應的類型。作者的描述還有大岔路沒決定時（例如推理是本格還是社會派、仙俠要雅還是要爽），**最多問三個問題**，一次問完；每題給兩三個選項加一句說明。作者說「你決定」就選最常見、最好寫的那個，在匯報裡說明。
2. 逐項過 style-dimensions.md，決定哪五到八項是這個文風的核心，寫深；其他一句帶過或留範本註解。
3. 寫「核心一句話」：一句話抓住整個文風的態度。
4. 寫範例段落。範例裡的人名、地名用中性的原創名字，或用本書已經有的角色。
5. 寫進檔案，匯報：核心一句話、你選了哪幾項當核心和理由、作者需要確認的地方。

### B. 分析樣本（作者貼了自己的文字）

1. 先用程式統計（不用猜）：
   ```
   python scripts/style_metrics.py 樣本.md [更多檔案] --exclude 人名1,人名2
   ```
   樣本放在暫存檔；`--exclude` 放本書的人名、地名，避免它們佔滿「高頻詞組」。樣本至少 300 字，3000 字以上比較準。把輸出的表格整節放進文風檔（標題是「## 文字指標（程式統計）」，放在「範例段落」之前；已經有這一節就整節換掉）。
2. 再讀樣本，對照十三個面向找特徵：哪些地方和一般寫法不一樣？舉出樣本裡的具體句子當證據（在匯報裡，不寫進規則）。
3. 把特徵寫成規則。指標表裡的數字可以轉成範圍描述寫進規則（平均句長 12 字 → 「句子偏短，一般敘述十來字」）。
4. 範例段落：從樣本挑最有代表性的兩三段（可以節錄），標上場景類型，寫「我喜歡它哪裡」。樣本缺的場景類型，可以依規則補寫一段，標明「（補寫）」。
5. 匯報：你歸納的重點、證據、不確定的地方（「樣本裡沒有打鬥戲，動作規則是我推測的」）。

### C. 依意見修改

1. 讀現有文風檔。只改和作者意見相關的條目，其他保持原樣。
2. 作者的意見和既有規則衝突時，以新意見為準，舊規則刪掉或改寫，不要兩條並存。
3. 作者的寫法會被去 AI 味規則誤擋時，寫進「允許的例外」並附用途。
4. 匯報用「舊 → 新」列出每一條改動。

### D. 試寫

1. 照文風檔寫一段 200～300 字的場景。作者指定了情境就照寫；沒指定就挑最能考驗這個文風的情境（通常是對白加一點動作）。
2. 寫完自評：逐條列出這段示範了哪幾條規則，以及哪條規則很難遵守或規則之間打架（這通常代表規則要改）。
3. 試寫段落**不寫進文風檔**，除非作者說「這段放進範例」。

## 完成前自查

- [ ] 每一條規則都能拿來檢查一段文字嗎？
- [ ] 禁忌都有替代做法嗎？
- [ ] 有「核心一句話」嗎？
- [ ] 範例段落至少三段、有標籤、有「我喜歡它哪裡」嗎？
- [ ] 沒有抄任何參考作品的原文、人名、專有名詞嗎？
- [ ] 總長在 1500～3000 字之間嗎？
- [ ] 全部是台灣繁體中文、台灣用語嗎？
- [ ] 「## 範例段落」和「## 文字指標（程式統計）」兩個標題原樣保留嗎？（工作台靠這兩個標題找內容）

## 注意

- 本 skill 不寫正文，試寫段落除外。
- 不要把作者在舊檔裡寫的內容默默刪掉；要刪就在匯報裡說。
