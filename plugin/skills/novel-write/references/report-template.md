# 給作者的匯報

匯報只講三件事：**寫了什麼、要作者決定什麼、下一步**。用故事的話說，不講檔名、欄位、步驟編號。伏筆提到編號時一定附上故事標籤，例：「伏筆 F007（那封沒寄出的信）」。

## 寫完一章

```
第{N}章《{章名}》寫好了，約 {字數} 字。
這章：{兩三句講發生了什麼，停在哪個鉤子上}。
{有新增的具名人物或設定時：「新加了 {誰／什麼}，{一句說明}，已經登記。」沒有就刪掉此行}
{有需要作者注意的事：例如主角的功勞被別人拿走、提前動用了某個底牌、和章綱有出入。沒有就刪掉此行}
{自查結論一句話：「自查過設定和前文，沒發現衝突」或「發現 {什麼} 前後不一，已依前文修正」}
下一章：第{N+1}章《{章名}》，要接著寫嗎？
```

下一章沒有章綱時，最後一行改成：「第{N+1}章還沒有章綱，要我先排章綱嗎？」

## 一次寫多章（最多三章）

```
這次寫了第{N}～{M}章，共約 {總字數} 字。
- 第{N}章《{章名}》：{一句話}
- 第{N+1}章《{章名}》：{一句話}
- 第{M}章《{章名}》：{一句話}
{新增人物或設定，一行一個}
{需要作者注意的事}
{自查結論一句話}
下一章：第{M+1}章，要繼續嗎？
```

## 需要作者決定（先問作者級的新增物）

```
第{N}章寫到一半，{多出了一樣東西／我想加一樣東西，還沒寫}，需要你決定：{用故事的話說是什麼}。
它會影響 {後面哪段劇情或哪個已定安排}。
1. {留下／加上}，我把後面的大綱一起調整
2. {刪掉／不加}，照原章綱寫
我建議選 {1/2}：{一句理由}。
這章先不算完成，等你決定再往下。
```

## 字數差太多

```
第{N}章寫完了，比目標{少／多}約 {差額} 字（目標約 {目標}，現在 {實際}）。{一句原因，例：「章綱的事寫完就到這裡了，硬撐會注水」}
你想怎麼處理？
1. 就這個長度（推薦）
2. 我調整章綱或字數目標後重寫
3. {少的時候：「補一個場景：{具體建議}」／多的時候：「我刪減到目標長度」}
```

## 寫不下去、要停

```
第{N}章還沒辦法寫：{白話說缺什麼，例：「這章還沒有章綱」「上一章寫完後追蹤資料還沒更新」}。
建議 {一個動作}，可以嗎？
```
