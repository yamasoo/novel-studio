# 正文寫作技法

寫正文前讀一次（同一個對話中讀過就不用重讀）。這裡是通用技法；與本書 `設定/文風.md` 衝突時，以文風.md 為準。

## 一、場景：每場戲都要有變化

一場戲 = **目標 → 阻礙 → 變化**。
- 開場就讓讀者知道這場戲裡誰想要什麼。
- 阻礙要具體：一個人、一句話、一道門、一個規矩。
- 結束時局面要變：關係變了、資訊變了、處境變了、目標變了。

寫完一場戲問自己：刪掉這場，故事會少什麼？答案是「沒少什麼」就要改。

## 二、情緒：呈現，不要宣告

最容易寫出 AI 味的地方。情緒要讓讀者自己感覺到，而不是被告知。

**三種落地方式：**
1. **動作**：角色在情緒下做了什麼。不是「她很緊張」，而是她把茶杯轉了三圈，一口都沒喝。
2. **物件**：讓情緒附著在具體的東西上。不是「他很想念母親」，而是他還留著那件洗到發白的舊圍裙，掛在門後沒人敢動。
3. **反應鏈**：刺激 → 身體的第一反應 → 想法或選擇 → 行動。不要跳過中間直接寫結論。

**分寸：**
- 允許偶爾一句直白的情緒，放在最需要的位置，效果反而更強。全部禁止直寫會變得做作。
- 大情緒不等於大量描寫。越痛的地方，句子往往越短、越少形容詞。
- 不要每個情緒都配一個微表情（嘴角、眼神、瞳孔）。微表情是調味料，不是主菜。

## 三、對白

### 每句對白至少做一件事
推進劇情、揭露人物、製造張力、傳遞資訊（而且要藏在衝突裡）。只是寒暄、只是交代資訊的對白，刪掉或改寫。

### 潛台詞
真實的人很少把真心話直接說出口。角色有想隱瞞的東西時，對白就有張力。

讓讀者看見表裡不一的五個管道：
1. **話語**：他說出口的立場（可能是假的）
2. **肢體**：不自覺的小動作
3. **生理反應**：心跳、手心出汗、喉嚨發緊（視角角色才能感覺到）
4. **內心**：視角角色心裡的真實反應
5. **聲音**：語速、音量、停頓突然變了

讀者透過這些管道之間的落差看見真相，就不需要敘述者解釋。潛台詞要讓讀者讀得懂，即使對話中的其他角色沒察覺。

### 每個人說話要不一樣
- 照角色的聲音卡寫（`設定/角色/` 的「說話方式」）。
- 檢驗：遮住說話者，讀者能不能猜出是誰？
- 不是每個人都很會說話：有人詞不達意、有人答非所問、有人只講半句。
- 不是每個問題都會被回答：迴避、轉移話題、反問，都比正面回答更有戲。

### 對白標記
- 「說」是最好的對白動詞，不用刻意換成「沉聲道」「淡淡地說」「冷冷開口」。
- 很清楚是誰在說話時，連「說」都可以省。
- 不要在每句對白後面掛一個「帶著一絲……」的狀語。

## 四、轉場

讀者換場時最容易迷路。每次轉場要交代清楚：
- **時間**：過了多久？（「半個時辰後」「第二天清晨」）
- **空間**：現在在哪？用一個具體的感官細節定位，而不是一段環境描寫。
- **情緒承接**：上一場的情緒在新場景裡怎麼延續或轉變？角色不會一換場就忘了剛才的事。
- **視角**：如果換了視角角色，第一句就讓讀者知道現在是誰的眼睛。

快切是允許的，但不能剪斷因果、人物狀態和關係。

## 五、爽點場面怎麼寫

1. **鋪墊可指認**：爆發前，讀者要看得到主角的準備或被壓抑的過程。
2. **出手乾脆**：關鍵動作寫得短、準、有畫面，不要用一堆形容詞堆「氣勢」。
3. **反應鏈是爽感的主體**：寫在場不同人的不同反應——震驚的、不服的、後悔的、重新評估的。爽感來自別人認知的翻轉。
4. **給結果**：打完之後，主角實際拿到了什麼（名聲、資源、地位、情報）。
5. **不要替讀者喊爽**：不寫「這一刻，所有人都被震撼了」這種總結句，讓反應鏈自己說話。

## 六、節奏與句子

- **句子長短交錯**：一直很長會悶，一直很短會像電報。緊張時短、舒緩時長。
- **段落要有呼吸**：手機閱讀時，長段落會勸退讀者。一般敘述 3～5 行換段；重要的一句可以單獨成段，但不要每句都單獨成段。
- **描寫跟著動作走**：環境描寫最好是角色在動作中注意到的，而且跟此刻的處境有關。可以搬到任何場景的環境描寫，就是套話。
- **比喻要準、要少**：比喻最好來自角色的生活經驗（屠夫看人像看肉、帳房看人像看帳本）。萬用比喻（像潮水、像刀、像命運的齒輪）能刪就刪。

## 七、資訊揭露的邊界

- 遵守 `追蹤/時間線.md` 的「讀者目前知道」。還沒揭示的真相，敘述者不能說破，也不能用「他不知道的是」「殊不知」偷偷預告。
- 限知視角時，只寫視角角色能看到、聽到、想到的。
- 遵守章綱的「禁止事項」。
- 不提前動用後面才解鎖的能力或底牌。

## 八、寫完後的三類 AI 腔自查

檢測工具抓不到這三類，要逐段重讀：

1. **替讀者點題**：用工整的對仗句、金句、排比，把這段的意義總結出來。
   → 刪掉。如果刪掉後讀者看不懂，代表前面的呈現不夠，回去補動作或細節。
2. **敘述者跳出來解釋**：總結角色情緒（「她終於明白……」）、解釋動機（「他之所以這樣做，是因為……」）、把章綱的結論直接寫出來。
   → 改成人物的動作、對白、物件，讓讀者自己看出來。
3. **章尾的感悟、昇華、預告**：「這一夜，注定無人入眠」「她不知道的是，更大的風暴即將來臨」「從這一刻起，一切都不一樣了」。
   → 停在具體的畫面、動作、一句對白上。

另外檢查：
- **工程詞外洩**：正文裡不能出現「第X章」「上一章」「伏筆」「章綱」「讀者」這類寫作用詞（除非故事裡真的有這些東西）。
- **章綱照抄**：章綱的情節點是給你的指示，不是現成的句子。正文要把它展開成場景，不是把章綱的句子換個說法連起來。

## 九、章末

- 停在**變化**上，不停在總結上。
- 停在具體的畫面、動作或一句話上。
- 照章綱規劃的鉤子類型寫；章綱沒寫時，依本章功能選（見 novel-outline 的章末鉤子說明：未解問題、危機、反轉、新目標、輕預告、情緒餘韻）。
- 下一章的第一拍要能接住這個結尾。
